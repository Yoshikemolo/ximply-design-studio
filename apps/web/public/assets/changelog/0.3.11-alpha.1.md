# 0.3.11-alpha.1 — Blue ruler cursor markers

## Breaking changes

None.

## New features

- Show a blue cursor projection on each visible ruler: a vertical mark at X on the horizontal ruler and a horizontal mark at Y on the vertical ruler.

## Improvements

- Keep markers aligned through zoom and scrolling, independently of the full-canvas cursor-axes setting. Hide them when the cursor leaves the canvas or an editing dialog is active.

## Fixes

None.

## Security

None.

## Engineering

- Reuse viewport-aware cursor coordinates and noninteractive overlays without changing document or preference formats.
