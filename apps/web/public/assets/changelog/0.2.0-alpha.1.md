# 0.2.0-alpha.1 — First local editor

A single-user alpha for local testing. Builds and automated tests have passed;
Docker runtime and visual browser acceptance remain to be verified locally.

## Breaking changes

None.

## New features

- Draw editable rectangles, ellipses, freehand vector paths and text.
- Select, move, resize and rotate layers; control visibility, locking, opacity, order and blending.
- Import PNG, JPEG and WebP images; paint and erase raster pixels with undo and redo.
- Adjust image brightness, contrast, saturation and blur without discarding the source image.
- Save and reopen editable .ximply files; export flattened PNG or SVG with embedded raster layers.
- Inspect separated document planes in a Three.js spatial view with orbit, pan and zoom.
- View bundled Markdown release notes in About and select versions with a shareable version URL.

## Improvements

- Add a responsive workspace, collapsible and reorderable side panels, centralized themes and English/Spanish interface labels.
- Keep small drafts in browser storage and provide explicit project-file downloads for larger documents.

## Fixes

- Resolve the API authentication dependency and preserve source-version identity in API health and OpenAPI metadata.
- Preserve transparent backgrounds when rendering separate spatial layers.

## Security

- Protect server artifact save/open with a bearer token configured locally and kept out of the frontend bundle.
- Bind the Docker preview to loopback, validate native documents and restrict artifact identifiers to generated UUIDs.
- Limit project size, layer counts and local artifact storage; reject remote image URLs in native project data.

## Engineering

- Pin Angular 22.1.7 and its compatible build/test toolchain; record package lockfiles and container image digests.
- Add domain, renderer pixel, editor-state and API tests plus local Bash/PowerShell launchers.
- This preview does not implement production Keycloak integration, PostgreSQL/TypeORM transactions, collaboration, desktop windows, third-party plugin installation or full Illustrator/Photoshop format compatibility.
