# 0.13.4 — Model access in the connection test

A feedback patch on 0.13.3. It remains a local preview: the strict quality gate is paused and
outstanding.

## Breaking changes

None.

## New features

None.

## Improvements

- Test connection in Settings > External tokens also checks, at no cost, that the token's project can use the image model and the text model of the agent tools, and names any it cannot use with the way to allow it.

## Fixes

None.

## Security

- A refused generation is written to the server log with its action, result type, model and the provider's reason; the log never holds the prompt, the pictures or the token.
