# 0.3.4-alpha.1 — Bezier selection and constrained handles

## Breaking changes

None.

## New features

- Edit anchors and direction handles on a selected curve using Selection as well as Direct Selection.

## Improvements

- Hold Shift while dragging anchors, handles or new Pen tangents to constrain their direction to the angle increment in Settings, relative to the canvas axes.
- Hold Ctrl or Alt while dragging a handle to move it independently without moving the opposite handle. Unmodified smooth handles remain coupled.
- Preserve curve controls and the active gesture when Ctrl changes during a drag; temporary Ctrl selection remains available while idle.

## Fixes

- Preserve selected anchors when Shift starts a constrained drag; a Shift-click can still deselect an anchor.
- Clear stale node selections when changing layers and ignore direction handles hidden by Settings.
- Apply path edits with the effective selection tool instead of accidentally invoking the underlying drawing or anchor-deletion tool.

## Security

None.

## Engineering

- Add geometry and routing regression checks, including transformed paths, modifier changes, undo and cancellation. Native files and API contracts remain compatible.
