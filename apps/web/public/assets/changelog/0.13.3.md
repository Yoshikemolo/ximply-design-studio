# 0.13.3 — Bitmap or vector results and a searchable prompt library

A feedback patch on 0.13.2. It remains a local preview: the strict quality gate is paused and
outstanding, and vector requests have not yet been verified against the live provider.

## Breaking changes

None.

## New features

- Result: choose Bitmap or Vector in the prompt controls. Vector sends the drawing itself as SVG with the images, asks the model for one SVG of groups with ids, solid colours and clean paths, and inserts the answer as editable paths and groups. Convert to paths and groups always gives a vector result.
- Saved prompts can be searched by words, in the title, text or action, ignoring case and accents, and every prompt can be removed after a confirmation; removing a default hides it until Restore default prompts. Saved prompts keep their result type, and a new default, Recolour the drawing, gives a vector result.

## Improvements

- Vector results use the current balanced model with image input by default, which the text model setting can change; when a model does not accept a temperature, the request is sent again without one and the creativity stays in the instruction.

## Fixes

None.

## Security

- Vector results are locked, in the panel and in the API, when the context holds pictures, since they would mean tracing them.

## Engineering

- Recorded SC-0157 and the search and removal oracle of SC-0152.
