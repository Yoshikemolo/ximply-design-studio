# 0.13.7 — Vector results from pictures

A feedback patch on 0.13.6. It remains a local preview: the strict quality gate is paused and
outstanding.

## Breaking changes

None.

## New features

- Vector and Convert to paths and groups work on pictures: the model traces them into editable paths and groups with flat colours sampled from the picture, one group per picture and nested groups per region, placed where the picture sits.

## Improvements

- The source SVG of a vector request carries only the vector objects; pictures travel once, as pixels in the PNG images.

## Fixes

None.

## Security

- The lock of 0.13.3 on vector results for pictures is lifted by owner decision; the drawing the model answers with is still screened before it is imported.

## Engineering

- SC-0157 replaces the picture lock oracle with the tracing oracle.
