# 0.3.2-alpha.1 — Two-column tool rail

A toolbar layout feedback patch for the drawing preview.

## Breaking changes

None.

## New features

None.

## Improvements

- Arrange toolbar buttons in two columns, grouped by selection, drawing, paint, transformation and navigation, followed by appearance controls.
- Expose Selection and Direct Selection side by side while preserving tool flyouts, configured shortcuts and tooltips.
- Place related operations together and adjust the workspace width and flyout placement for the wider rail.

None.

## Security

None.

## Engineering

- Preserve native document and API compatibility; no data migration is required.
