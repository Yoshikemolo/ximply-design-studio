# 0.8.0 — Scaling, shearing, distorting and envelopes

This release follows the sections Scaling, shearing, and distorting objects and Reshape
using envelopes of the Illustrator CS3 Help: the Shear tool and dialog, the Scale dialog
and Transform Each, the Free Transform tool with its shear, free distort and perspective,
the seven liquify tools, and envelopes made from a warp, a mesh or a top object. It
remains a local preview: the strict quality gate and visual acceptance of this release
are still outstanding, so the version number records delivered scope, not certified
quality.

## Breaking changes

- Documents that hold an envelope are refused by 0.7.0 and earlier editors and APIs, which do not know the field (ADR-0034, proposed). Migration: to open such a document in an earlier version, expand or release its envelopes first.
- Documents that hold a gradient mesh are refused by 0.7.0 and earlier (ADR-0035, proposed). Migration: keep a copy, or remove the gradient meshes before opening the document in an earlier version.

## New features

- Shear with the Shear tool, beside Scale and Reshape: a drag that starts up or down shears along the vertical axis and one that starts sideways along the horizontal axis, about the pivot, with Shift keeping the original width or height; a click moves the reference point first, and Alt-click moves it and opens the Shear dialog, which takes an angle from -359 to 359 along a horizontal, vertical or angled axis, with Copy. Every object keeps its kind, text and pictures included.
- Scale with the Scale dialog, from a double-click on the tool, Alt-click or Object > Transform > Scale: Uniform or Non-Uniform percentages, negative ones reflecting, Scale Strokes & Effects and Copy.
- Transform with the Free Transform tool (E): its box moves the selection from inside, scales it from a handle against the opposite one, Shift keeping the proportions and Alt scaling from the centre, and rotates it from outside, Shift by 45 degrees. Holding Ctrl+Alt while a side handle is dragged shears along that side, Ctrl on a corner handle distorts freely and Shift+Alt+Ctrl distorts in perspective. Ctrl works whether it is pressed before the drag or during it. Three buttons in the context bar, as the tool's widget in later Illustrator versions has them, choose Free Transform, where a corner scales, Free Distort, where it moves alone, and Perspective Distort, where it moves with its neighbour, so no key needs to be held. Distorted shapes become paths that pass within half a pixel of the exact map; text, pictures, symbols, dimensions and floor-plan objects are left as they are and named.
- Reshape with the liquify tools, in a family of their own: Warp (Shift+R) pushes the outline with the drag; Twirl turns it about the brush, counterclockwise for a positive rate; Pucker pulls it in and Bloat pushes it out; Scallop, Crystallize and Wrinkle add curved, spiked and wrinkled details. They act inside an elliptical brush drawn at the cursor, keep acting while the button is held, reshape only the selection when there is one and every unlocked vector object under the brush when there is none, and add anchors at the spacing of Detail. Alt-drag sizes the brush, Shift+Alt as a circle, and a double-click on the tool opens its options with the ranges of the manual, kept between sessions.
- Reshape objects with envelopes, from Object > Envelope Distort: Make With Warp (Alt+Shift+Ctrl+W) with the Warp Options and a live preview, the fifteen styles shown by pictures, the axis, Bend and the horizontal and vertical Distortion; Make With Mesh (Alt+Ctrl+M) with its rows and columns; and Make With Top Object (Alt+Ctrl+C), the topmost selected shape taking the others. The objects stay whole inside one Envelope. Edit Contents (Shift+Ctrl+V) brings them out to be edited with every tool while the envelope keeps drawing them through its mesh, and Edit Envelope takes them back, recentred; Reset With Warp and Reset With Mesh, which can keep the shape, replace the mesh; Envelope Options sets the Fidelity; Release gives back the objects and the envelope's shape, and Expand leaves the distorted paths. The Direct Selection tool drags the points and handles of the mesh, the Mesh tool (U) adds a row and a column through a click on any envelope, taking it without selecting it first, and Delete on a chosen point removes them. The canvas, SVG and PDF draw the same distortion. Text is outlined first (Ctrl+Shift+O).
- Paint with gradient meshes. A first click of the Mesh tool (U) inside a shape turns it into a mesh whose new mesh point takes the fill colour, or keeps the colour there with Shift; later clicks add mesh points, Alt-click deletes one with its lines, and a drag moves one. With a mesh point chosen, the fill colour goes to that point. Object > Create Gradient Mesh makes a regular mesh with rows, columns, the Flat, To Center or To Edge appearance and a highlight. The colours blend across each patch on the canvas and in SVG, and PDF carries the mesh as a Coons patch shading.
- Transform each selected object about its own reference point with Object > Transform > Transform Each (Alt+Shift+Ctrl+D): scale, move, rotate and reflect, with the nine reference points and Copy.

## Improvements

- Show in the about screen the logo of the header beside the name of the product, the licence the build carries with the SHA-256 of its LICENSE file, and the credits of the footer with the links to LinkedIn, Ximplicity and GitHub in the same style. An empty page shows the brand of the header above its call to action instead of a blue x.
- Save a project under another name with File > Save As (Shift+Ctrl+S). Where the browser lets a page write to a file, its own dialog chooses the name and folder, the document takes that name, and later saves with Ctrl+S write to the same file instead of downloading a new one; elsewhere the name is asked for and the project is downloaded under it. The page writes only to the file chosen in that dialog.
- Show or hide the strip of document tabs from View > Layout, like the context bar; the canvas takes the height it leaves.
- Show or hide the context bar from View > Layout, like the other blocks of the workspace; the canvas takes the height it leaves, and the choice is remembered.
- Zoom as Illustrator does. Ctrl+Space holds the Zoom tool over any tool and Ctrl+Alt+Space holds it in reduce mode: a click zooms in, or out, to the next preset about the point clicked, which comes to the centre, and a drag zooms to the area dragged, without drawing; letting the keys go gives back the tool in use. The Zoom tool itself zooms in with a click, out with Alt, to an area with a drag whose marquee Space moves, and to 100 percent with a double-click, as View > Actual Size (Ctrl+1) does; a double-click on the Hand tool fits the page, and View > Zoom In and Zoom Out step through the same presets. A finger tap and a finger drag with the Zoom tool work the same on a touch screen, and two fingers still zoom the view.
- Fill the icon of the Selection tool, as Illustrator draws its black arrow, and keep the Direct Selection tool's icon as an outline, so the two are told apart at a glance.
- Drag with the Scale tool as in Illustrator: the point pressed follows the pointer on each axis about the pivot, Shift keeps the proportions on a diagonal drag and scales one axis on a drag along it, and a click sets the reference point.
- Repeat a scale or a shear with Transform Again (Ctrl+D) as the same map about the same point.
- Gather the transformations of the selection in an Object > Transform section of the menu.

## Fixes

- Turn the selection with the Rotate tool by the angle measured about its pivot, as Illustrator measures it about the reference point. The angle was measured about the centre of the object, so with the pivot elsewhere a pointer passing near the centre swung the object round the pivot and could carry it off the page; right at the pivot the angle now holds until the pointer is clear of it.
- Draw the icons of the active toggles of the context bar white on their blue background in the light theme, where they were dark, as they already were in the dark theme.
- Keep the name of the page just above it, and above the rulers when they are shown; it was placed against the corner of the work area, where the rulers covered it once the page was larger than the view.
- Open the menus from the menu button on a phone: a tap on File, Edit, View, Object or Help reached the backdrop of the drawers, drawn above the header, and the menu never unfolded. Every dialog, popover, list of tools and context menu fits the screen of a phone upright or on its side, scrolling where it is taller.
- Close the appearance popover with a press anywhere outside it, as the list of a tool family closes; while the colour picker's eyedropper takes a colour from the page, the popover stays open. Several listeners of the page for the same press were not all called, so the popover never closed.
- Show the Gradient tool in the column of tools, with the Mesh tool beside it, and the liquify and Free Transform tools after Scale; the Gradient tool of 0.7.0 was only reachable with G.
