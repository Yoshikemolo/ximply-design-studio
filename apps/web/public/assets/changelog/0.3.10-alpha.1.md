# 0.3.10-alpha.1 — Editable object blends

## Breaking changes

- Optional native-v2 blend definitions require an updated reader. Migration: preserve original documents before saving live blends; older readers may reject the new metadata. Expand blends before exchanging editable objects without the live relation.

## New features

- Blend two compatible vector objects or equally sized vector groups from back to front, interpolating vertices, handles, geometry, colors, alpha, stroke width and opacity.
- Edit intermediate step count and linear, ease-in, ease-out or ease-in-out distribution.
- Edit retained endpoints and regenerate intermediate objects; expand to independently editable objects or release to retain only the original endpoints.

## Improvements

- Expose localized blend actions and endpoint editing controls; expanded objects support ordinary grouping and ungrouping.
- Preserve undo and native save/load, and export materialized intermediate artwork through existing SVG/PNG rendering.

## Fixes

None.

## Security

None.

## Engineering

- Validate blend metadata and reference ownership in frontend/API, with bounded subdivision, layer count and group depth.
- Support compatible vector contour topology and equal-cardinality groups. Text/image blends, editable spines and path-following orientation remain outside this preview.
