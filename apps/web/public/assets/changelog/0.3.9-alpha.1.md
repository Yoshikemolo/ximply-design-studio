# 0.3.9-alpha.1 — Stroke geometry and style tools

## Breaking changes

- Optional native-v2 strokeStyle metadata requires an updated reader. Migration: preserve original documents before saving new stroke properties; older readers may reject new metadata. Absent metadata retains the legacy centered round stroke.

## New features

- Configure center, inside or outside stroke alignment on closed vector contours through the shared stroke picker.
- Choose round, bevel or miter joins and butt, projecting square or round caps using localized icon controls.
- Sample semantic object styles with Eyedropper and apply current styles with Paint Bucket, choosing fill, stroke or both. Stroke transfer includes alpha, width, alignment, joins and caps.

## Improvements

- Preserve existing shortcut assignments when introducing style tools; conflicting new default bindings remain unassigned.
- Record style application in undo history and preserve new stroke defaults when drawing subsequent objects.

## Fixes

- Keep stroke geometry consistent between canvas and SVG, including compound closed contours and independent paint alpha.

## Security

None.

## Engineering

- Validate stroke metadata in frontend/API native-v2 readers and symbol definitions.
- Open contours and live text use centered stroke alignment. Style sampling reads object properties, not image pixels; bucket applies object styles rather than region flood filling or live-paint topology.
