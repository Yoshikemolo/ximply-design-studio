# 0.3.5-alpha.1 — Appearance palette, units and magnetic layout aids

## Breaking changes

- Native-v2 now supports absent/alpha paints and guide metadata that older readers may reject or discard. Migration: preserve original files and use this version for new saves; reverting the application does not convert new files. Guides are intentionally omitted from PNG and SVG exports.

## New features

- Open the same fill/stroke picker from Appearance, the inspector or overlapping swatches below the two-column toolbar. Choose a color, no color, black or white and edit independent color opacity and stroke width.
- Swap fill and stroke without losing their transparency. Paint alpha remains separate from overall layer opacity.
- Configure distance and font units independently using px, pt, mm, cm, inches or feet. Rulers and dimensional controls convert their display and input without resizing artwork.
- Show or hide rulers, guides and grid with paired magnetic buttons. Configure ruler step, grid spacing and each source's magnetic radius in Settings.
- Drag horizontal or vertical guides from rulers, reposition them and drag them outside the artboard to delete them. Guides persist as ordered layers with visibility, locking and undo support.
- Reorder layers by dragging, preserving grouped artwork together.

## Improvements

- Toggle Appearance, Workspace and Measurement context blocks through View > Layout; visibility preferences persist.
- Move theme switching beside the language selector in the header, using sun/moon icons for the current theme.
- Match snapping distance to screen pixels across canvas zoom and preserve the pointer offset while moving objects.

## Fixes

- Keep guide layers out of artwork rendering, exports, 3D preview and normal artwork operations.
- Preserve independent fill/stroke alpha through native files, authenticated API storage, Canvas and SVG.

## Security

- Validate paint strings, guide metadata, finite coordinates and bounded measurement preferences without weakening storage authentication.

## Engineering

- Use 96 document pixels per inch and 72 points per inch; these units do not assert physical monitor calibration.
- Keep ruler generation bounded and canonical document geometry in pixels. Full quality certification remains separate from feature-branch preview publication.
