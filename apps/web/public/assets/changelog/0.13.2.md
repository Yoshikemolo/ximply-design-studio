# 0.13.2 — Current image model

A feedback patch on 0.13.1. It remains a local preview: the strict quality gate is paused and
outstanding.

## Breaking changes

None.

## New features

None.

## Improvements

- Picture actions use `gpt-image-2.5-flare`, OpenAI's recommended image model, instead of `gpt-image-1`. `XDS_OPENAI_IMAGE_MODEL` still chooses another, such as `gpt-image-2.5-sunburst` for the most precise edits.

## Fixes

- When the OpenAI project of the token cannot use the image model, the panel says to allow the model in the project limits or to verify the organization.

## Security

None.

## Engineering

- SC-0154 names the default model and the setting that changes it.
