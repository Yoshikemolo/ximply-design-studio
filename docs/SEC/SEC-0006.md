# SEC-0006 — Durable command integrity

Status: Proposed
Owner: Jorge Rodriguez

## Constraint
Use idempotency, revision preconditions and transactional outbox.

## Verification oracle
Duplicate/reordered events or crashes never produce two committed edits.

## Enforcement
Server-side checks and adversarial integration tests; client visibility is UX only.

## Evidence
Planned. No implemented security control is claimed by this document.
