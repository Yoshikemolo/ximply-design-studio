# SEC-0008 — Supply chain and CI

Status: Proposed
Owner: Jorge Rodriguez

## Constraint
Pin dependencies/actions; isolate untrusted contributions; keep secrets outside source and logs.

## Verification oracle
Fork PR receives no secrets or privileged runner; lockfile drift blocks.

## Enforcement
Server-side checks and adversarial integration tests; client visibility is UX only.

## Evidence
Planned. No implemented security control is claimed by this document.
