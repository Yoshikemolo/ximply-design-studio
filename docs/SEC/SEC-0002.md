# SEC-0002 — Revocation and session lifetime

Status: Proposed
Owner: Jorge Rodriguez

## Constraint
Recheck membership at commit, subscription, URL issue and job publication; disconnect revoked sessions.

## Verification oracle
Removal during an active connection prevents its next edit and delivery.

## Enforcement
Server-side checks and adversarial integration tests; client visibility is UX only.

## Evidence
Planned. No implemented security control is claimed by this document.
