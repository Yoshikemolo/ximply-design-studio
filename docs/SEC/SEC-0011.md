# SEC-0011 — Licence authority and seat integrity

Status: Proposed
Owner: Yoshikemolo

## Constraint

Only a trusted issuer's valid signature may grant entitlements. A hash alone is not
authority. Local admins cannot widen vendor grants; tokens, plugin signatures and
licences are separate. Validate scope/time/revocation/serial and allocate seats
transactionally. Development trust roots are rejected in production.

## Verification

Independent cryptographic vectors, modified payloads, algorithm confusion, wrong
issuer/audience/key, expired/revoked grants, parallel final-seat allocation, clock
rollback and offline lease limits. Preserve work under licensing failure.

## Evidence

Planned. No cryptographic implementation or production licence has been issued.
