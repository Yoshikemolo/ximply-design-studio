# Carried faces and an in-process font reader for text outlines

Status: Proposed; the preview implementation does not constitute acceptance, and this
record needs the owner review that a new runtime dependency requires.

## Context

Turning text into shapes needs the outlines of its glyphs. A browser draws text but
never exposes those outlines, and the families the studio offered were the ones
installed on the machine, whose files a web page cannot read and whose licences do not
allow shipping them. The owner asked for Create Outlines with the behaviour and the
keyboard shortcut of Illustrator.

## Proposed decision

Carry the faces and read them in process.

- The studio ships three faces under an open licence, each with the metrics of the
  family it stands for: Arimo for Arial and the sans-serif stack, Tinos for Times New
  Roman and the serif stack, Cousine for Courier New and the monospace stack. They are
  declared as web fonts and asked for first when text is drawn, so a document looks the
  same on every machine and the outlines come from the very file that drew it.
- Families with no carried twin, Georgia, Verdana and Trebuchet MS, keep their place in
  the list and are outlined with the closest carried face, which the editor reports.
- Outlines are read with opentype.js, a font parser under the MIT licence. It parses a
  file the application itself serves, in memory, and executes nothing from it. No font
  is fetched from another origin and no font chosen by a person is parsed, so the
  reader never sees a file the studio did not ship.

## Consequences

Text becomes artwork exactly as it is drawn, which is what Create Outlines means, and
the measured layout of existing documents is preserved because the carried faces keep
the metrics of the families they stand for. The shapes of the letters change slightly
where a system font used to be drawn, which is the price of drawing the same thing
everywhere. The bundle grows by the parser and by about two hundred kilobytes of font
files, and the notices file carries their licences.

## Alternatives considered

Tracing a high-resolution render of the text needs no dependency but produces stepped
contours that are poor for type, especially at small sizes. Letting a person load their
own font file would put an untrusted binary through the parser and was rejected for
this slice. Shipping the system families themselves is not permitted by their licences.

## Security and validation

A font file is data: it is fetched from the application, parsed in memory, never
executed, and a file that cannot be read leaves the text as it was. Oracle:
[SC-0100](../sc/SC-0100.md).
