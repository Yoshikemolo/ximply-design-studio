# ADR-0019 — Asymmetric signed licences with public fingerprints

Status: Proposed
Date: 2026-09-19
Owner: Yoshikemolo

## Context
A recomputable public hash cannot prove issuer approval.

## Proposed decision
Use a standard signed envelope, trusted public-key verification and a separate protected issuer; apply scoped time/seat/plugin grants.

## Alternatives
Unsigned hashes and shared browser secrets cannot enforce authenticity.

## Security, operational and performance impact
Key lifecycle, offline limitations, revocation and recovery UX must be tested.

## Migration and observability
Version contracts, retain audit-safe diagnostics and preserve document recoverability.

## Verification
Use linked SC acceptance oracles and fresh module analysis. No implementation is claimed.

## Supersedes
None. Human acceptance pending.
