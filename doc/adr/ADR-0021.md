# ADR-0021 — GitFlow environment promotion and scoped operations

Status: Proposed
Date: 2026-09-19
Owner: Yoshikemolo

## Context
Owner requires dev/feat/fix/qa/demo/release/main and safe cross-platform Docker runbooks.

## Proposed decision
New feat/fix work starts from dev; enforce conventional metadata and fresh Sonar gate, then controlled qa/demo/release promotion.

## Alternatives
Direct main development and automatic ungated deployment conflict with the requested workflow.

## Security, operational and performance impact
Targets, branch protection and deploy adapter must be configured; scoped cleanup never prunes unrelated resources.

## Migration and observability
Version contracts, retain audit-safe diagnostics and preserve document recoverability.

## Verification
Use linked SC acceptance oracles and fresh module analysis. No implementation is claimed.

## Supersedes
None. Human acceptance pending.
