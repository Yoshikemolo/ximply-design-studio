# Shared text composition and dictionary hyphenation

Status: Proposed; preview implementation does not constitute acceptance.

## Context and proposed decision

Store optional complete typography and textLayout objects on native-v2 text layers.
Keep legacy text rendering when both are absent. Validate the same shape and bounds
in frontend and API, including symbol definitions. Keep canonical pixel geometry.

A shared bounded layout engine receives font measurements from the renderer and
produces glyph positions consumed by both canvas and SVG. The editor recomputes
automatic frames using the same measurements. Fit shrinks rendered font size without
changing the stored base size. Frame sizing modes are mutually exclusive; fit is
available only for fixed frames. Preserve original source text during hyphenation.

Pin hyphen 1.14.1 and import only English and Spanish pattern modules. Upstream
package metadata declares ISC and describes CTAN pattern provenance. Retain its
distributed license in assets/THIRD_PARTY_NOTICES.txt; pattern-specific provenance
has not been independently audited. No network request is needed during composition.

## Consequences and limitations

Older native-v2 readers may reject added metadata. Preserve original files. Installed
fonts determine visual availability; there is no font download or embedded font.
Native textarea caret/selection cannot exactly reproduce every composed layout.
Character-range styles, linked frames, text on paths and advanced OpenType features
remain outside this preview. The dependency adds bundled pattern data and requires
license/provenance review before production acceptance.
