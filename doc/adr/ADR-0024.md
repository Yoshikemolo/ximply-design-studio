# Absent paint and nonprinting guide layers

Status: Proposed; implementation preview evidence does not constitute acceptance.

## Context

Artwork needs independently absent fill/stroke and document-persisted editable guides.
The current native model uses pixel geometry and ordinary ordered layers.

## Proposed decision

Represent absent fill/stroke as the exact literal none and independent color alpha as hex8 RGBA; keep background validation
unchanged. Skip canvas paint calls for absent paint and export SVG none attributes.
Use optional vertical/horizontal guide metadata on native-v2 path layers. Store guide
position in the existing x/y coordinates; do not duplicate artwork geometry as guide
state. Exclude guides from artwork rendering, export and normal geometry operations.
Keep them visible in the layer list with visibility, locking, ordering and undo.
Reject guide groups, symbol references and symbol definitions to keep ownership clear.

Persist display units and magnetic/layout preferences locally. Maintain canonical
pixel geometry and use 96 px/in and 72 pt/in conversions at the UI boundary. Magnetic
radii use screen pixels, converted by canvas zoom. Bound all tick/grid generation.

## Consequences and migration

This adds no runtime dependency or production persistence service. New native-v2
extensions are not guaranteed to work in older readers. Preserve original files and
use the updated reader for new saves. Exports intentionally omit editing guides.
Frontend and API validation, canvas pixels and SVG output need parity tests.
