# Vector dimensions with independent annotation sizing

Status: Proposed; implementation in a preview does not constitute acceptance.

## Proposed decision

Store an optional `dimension` object on native-v2 path layers. Linear dimensions
have two anchors; angular dimensions have three with the middle anchor as vertex.
Anchors and label position use layer-local coordinates. Derive world geometry and
measurement values after the layer transform, preserving annotation font and marker
sizes instead of shearing or nonuniformly scaling their appearance. Labels remain
horizontal. Angular values use the smaller angle in degrees; linear values convert
canonical pixels to the selected display unit and multiply by a positive scale.
Formatting specifies zero to eight decimals and a period or comma separator.

Dimension-line appearance uses the ordinary layer stroke; extension lines have
separate paint, width, gap and overshoot. Labels use layer typography and optional
text override. Optional `lineEnds` metadata provides independently styled start and
end markers, tip/base placement, size and a linked-edit preference. Share derived
geometry between Canvas and SVG instead of maintaining different annotation models.

Keep annotation anchors independent of source artwork identities. Snapping assists
placement; it does not introduce persistent constraints or CAD associativity.
Dimensions cannot become symbol definitions or live blend endpoints. No new runtime,
transport, storage adapter or third-party dependency is introduced.

Optional `regroupPath` records prior group membership after ungrouping. Restoration
uses current surviving layer objects, preserving their edits, and rejects locked or
incompatibly regrouped members. It participates in native save/open and history.

## Consequences and migration

Older native-v2 readers may reject or lose these extensions. Migration: preserve
original files and open new saves using this version or newer. SVG/PNG retain visible
annotations but do not preserve dimension semantics or regroup history. Reverting
code does not migrate saved documents backwards. Existing files without these fields
keep their prior behavior. Ruler subdivisions are preferences, not document changes.

This is a bounded vector annotation model, not a mechanical constraint solver or a
complete drafting standard. Associative updates, tolerances, baseline/chain dimensions,
radius/diameter dimensions and persistent geometric constraints remain future work.
