# Vector Paintbrush strokes carried by paths in the native format

Status: Accepted by the owner, Yoshikemolo, on 2026-09-22, after reviewing the
implementation released in 0.6.0. The change to the native format stands as decided.

## Context

The owner asked for drawing tools that behave as Illustrator CS3 describes them,
including the controls of the Paintbrush: Fidelity, Smoothness, Fill New Brush Strokes,
Keep Selected and Edit Selected Paths within a distance. In Illustrator the Paintbrush
draws a vector path and applies a brush to it; its options act on that path. The
studio's brush painted pixels into an image layer, so none of those options had a
path to act on, and a painted stroke could not be reshaped afterwards.

## Decision

Add a vector Paintbrush beside the raster brush, and let a path carry a brush.

- The Paintbrush draws a Bezier path fitted from the pointer with the same fitter as the
  Pencil, and applies a calligraphic brush to it: a nib of a diameter, a roundness and
  an angle, swept along the path. The path stays an ordinary editable path.
- A path layer may carry an optional `brushStroke` field in native format 2, with
  `kind` fixed to `calligraphic`, `angle` from -180 to 180 degrees, `roundness` from 0
  to 100 percent and `diameter` from 0.1 to 1296 pixels. The editor and the API
  validate it alike, and it belongs only to a plain path: never to a rectangle, an
  ellipse, a text, an image, a dimension or a generated object.
- The painted area is the band the nib sweeps plus the nib at each end of an open path,
  filled in the stroke colour and scaled by the stroke weight, so a weight of 1 paints
  the nib at its own diameter. The canvas, SVG and PDF all write that same area.
- The raster brush stays for painting into images, under its own name and without a
  key; B selects the Paintbrush, as it does in Illustrator.
- Scatter, art and pattern brushes are left out; only the calligraphic brush, which is
  Illustrator's default, is carried.

## Consequences

A brushed stroke can be redrawn, extended, simplified and reshaped like any path, and
it looks the same in every output. A document that carries a brush is refused by
earlier versions of the editor and the API, which do not know the field; the release
note states that as a breaking change with its migration. Drawings exported to SVG or
PDF lose the brush as a property: they keep the painted area as a filled shape, which
is what other programs can show. Nothing new is fetched or executed, and no new
dependency is added.

## Alternatives considered

- Smoothing the raster brush's pointer path before painting. It would add Fidelity and
  Smoothness but leave a picture that cannot be reshaped, and it would not be the tool
  Illustrator describes.
- Expanding every brushed stroke into a filled outline as soon as it is drawn. It would
  need no format change, but the stroke would stop being a path and its brush could no
  longer be changed or removed.
