# ADR-0022 — Ximplicity editorial restraint in a dense editing UI

Status: Proposed
Date: 2026-09-19
Owner: Yoshikemolo

## Context
Professional tools need usable density and a distinct coherent identity.

## Proposed decision
Use central semantic themes, restrained blue accents, stable docking, accessible command surfaces and accurate capability states.

## Alternatives
Marketing-card layouts and decorative glow consume canvas space and obscure editing hierarchy.

## Security, operational and performance impact
Token values are proposals, brand asset approval and task testing remain required.

## Migration and observability
Version contracts, retain audit-safe diagnostics and preserve document recoverability.

## Verification
Use linked SC acceptance oracles and fresh module analysis. No implementation is claimed.

## Supersedes
None. Human acceptance pending.
