# Explicit stroke geometry and scoped appearance transfer

Status: Proposed; preview implementation does not constitute acceptance.

## Proposed decision

Use an optional complete strokeStyle object on native-v2 layers with alignment,
join and cap enums. Default absent metadata to center/round/round to preserve
existing artwork. Require matching frontend/API validation including symbol data.

For inside/outside alignment on closed vector contours, double stroke width and
clip to the appropriate interior/exterior region. Preserve the existing even-odd
fill semantics for compound contours and avoid alpha multiplication from repeated
painting. Open contours and live text remain centered. Set the same miter limit in
Canvas and SVG. Export distinct generated clip/mask identifiers rather than relying
on user layer names as identifiers. Use native cap/join semantics.

Style tools transfer semantic fill and/or stroke data, including color alpha and
stroke geometry, without copying layer opacity, transforms, text or image pixels.
History records applied edits atomically. Keep style scope visible as icon controls
with localized explanations. Respect locks and guide exclusions.

## Consequences and migration

No additional dependency or network service is required. New metadata may be
rejected by old readers; preserve source files and use the updated reader for new
saves. Appearance transfer does not implement region flood filling or live-paint
topology. Existing shortcut customizations must survive addition of tool commands.

Picking retains the editor's bounded geometric approximation at long miter tips
and square-cap corners. For mixed open and aligned closed contours in one layer,
separate stroke passes can accumulate alpha where their outlines overlap; centered
mixed contours retain a single stroke pass.
