# FEAT-0030 — Convert to pixel image

Status: Planned
Owner: Yoshikemolo
Iteration: ITER-0004
Dependencies: FEAT-0007, FEAT-0010
Decisions: none new; the result is an ordinary image layer of the current native format
Security controls: SEC-0005
Plan: [PLAN-0030-0001](../implementation/PLAN-0030-0001.md)

## Outcome

The designer converts the selected objects, or every visible layer of the document when
nothing is selected, into a PNG with transparency that is inserted as a new image object
above the selection. The source objects stay unchanged. The AI Tools of FEAT-0029 use
the same conversion to attach a preview of the canvas and of the selection to the
context of a request, so the model sees the same pixels the designer would get.

## Functional scope

- A sub-tool of the current Import image tool, named Convert to pixel image, reachable
  from the flyout of the image button in the tool rail and from the Import entry of the
  toolbar. For Illustrator parity the plan proposes listing the same command as
  Object > Rasterize…; that entry waits for the owner's confirmation.
- A dialog with the options that affect the result: resolution (72, 150 and 300 ppi and
  a custom value), anti-aliasing (none, art optimized, type optimized) and an added
  margin around the objects. The background is always transparent.
- With a selection, the image covers the visible bounds of the selected objects,
  strokes and effects included, and is inserted directly above the topmost selected
  object in its parent layer or group. With no selection, it covers every visible,
  printing layer of the document and is inserted at the top of the layer stack. Hidden
  layers and nonprinting guide layers (ADR-0024) are not drawn.
- The new image layer is selected, is named from the localized catalog and records one
  undo step. It is a placed picture, not a paint layer (ADR-0036), so its frame never
  changes by painting.
- The pixels are drawn by the same renderer as PNG export, so the result matches an
  export of the same area at the same resolution.
- A result without visible pixels, or beyond the image limits of the document, is
  refused whole with a message and leaves the document unchanged.
- A programmatic entry point returns the PNG without inserting it; FEAT-0029 uses it for
  its canvas and selection previews, capped at the resolution set in Settings.

## Acceptance scenarios

- [SC-0123](../sc/SC-0123.md) Selection converted to a transparent pixel image
- [SC-0124](../sc/SC-0124.md) Whole document conversion and refused conversions

## Implementation and evidence

Planned. Nothing of this feature is implemented.
