# FEAT-0029 — AI Tools panel and external agent provider

Status: Implementing
Owner: Yoshikemolo
Iteration: ITER-0007
Dependencies: FEAT-0006, FEAT-0007, FEAT-0030, FEAT-0032
Decisions: ADR-0037 (Accepted), ADR-0041 (Accepted), ADR-0015 (Proposed)
Security controls: SEC-0004, SEC-0012
Plan: [PLAN-0029-0001](../implementation/PLAN-0029-0001.md)

## Outcome

A designer asks an external agentic model to change the open document. The designer
decides exactly what context the model receives and which layers and objects it may
change. The model answers with a proposal of new or changed objects that the designer
previews and applies as ordinary, undoable editor commands. The first provider is the
OpenAI API; the adapter boundary admits other providers later without UI changes.

This feature delivers the first external-provider slice of the AI capability planned in
FEAT-0019. The MCP bridge and per-tool grants with expiry remain in FEAT-0019.

## Functional scope

### Shell and right column

- The primary button at the right end of the header, which opens the Export dialog today,
  becomes an AI icon button. It shows the right column on the AI Tools tab, and hides it
  when the column already shows that tab. Export stays available from File > Export….
- The right column header gets three tabs: **Properties** (the current Properties and
  Layers panels), **AI Tools** (this feature) and **History** (FEAT-0031). Tabs follow
  the tab pattern of the Settings navigation: keyboard arrows, visible focus, localized
  labels and tooltips.

The AI Tools entry of the advanced tools block in the tool rail (FEAT-0032) is the root of
this feature's tools and sub-tools; it opens the AI Tools tab when the panel exists.

### Settings > AI Tools category

A new Settings category, registered centrally and shown in the left column as required
by [UX direction](../product/ux-direction.md):

- Enable AI Tools, off by default. While off, no request can be sent and the panel
  explains how to enable it. The category and the panel require sign-in and a licence
  with the `ai-tools` permission (FEAT-0032); without them they explain what is missing.
- Provider, with OpenAI as the only first-slice entry, and a model identifier that the
  owner configures; the product does not hard-code a model name as a default promise.
- External tokens: each user enters their own OpenAI API token in a Settings category
  of its own, shown to users with the agent tools permission and to the super
  administrator. The API service stores it encrypted, tied to the user (ADR-0037 as
  amended on 2026-09-24). The browser never receives it back; the form shows only
  whether a token is configured and when it changed, and lets the user replace, remove
  or test it; the test reports success or the precise failure.
- Context defaults: include serialized document context, include a canvas preview image,
  include a selection image, and the preview resolution cap.
- Permission defaults: the change scope (selected objects only, the chosen layers, or
  every unlocked layer) and the allowed operations (add objects, modify objects, delete
  objects, add pixel images).
- Request limits: timeout and maximum attachment size.

### AI Tools panel (delivered in 0.12.0)

The owner decided on 2026-09-24 that the panel inserts what the model returns directly as a
new object, instead of the proposal flow below, which is deferred:

- Context: the selection, with its count, or the whole document (SC-0150).
- Quick actions: Change style, Reinterpret in a style, Rescale, Improve quality, Remove
  watermarks, Clean the background, Remove an object, and Convert to paths and groups;
  with no quick action the prompt is free.
- The prompt, and a creativity slider from Precise to Creative that the API turns into how
  freely the model may interpret the request (the temperature for drawings).
- Saved prompts: save under a title, mark as favourite and load from a list that includes
  seven defaults (SC-0152).
- A footer that stays at the bottom of the column: Generate, with a moving bar and the phase
  while the context is sent and the model answers, Cancel while it runs, and Repeat, which
  sends the last request again (SC-0151, SC-0153).
- Sent context: the prompt, the selected objects as data, the selection as PNG and the whole
  document as PNG, each labelled for the model, and the modifiers (SC-0151).
- The result is a new object above the selection, outside its groups: a picture fitted into
  the frame, or editable paths and groups for Convert to paths and groups (SC-0153).

### Deferred proposal flow

- A prompt field and a conversation for the current session of the open document.
- A context composer that lists every attachment that will be sent, each with a toggle,
  a thumbnail or summary and its size:
  - the serialized context of the document, or of the chosen layers only;
  - a preview of the whole canvas as a PNG made by the FEAT-0030 rasterizer;
  - a PNG of the selected objects made by the same rasterizer, when there is a selection.
- A scope control showing which layers and objects the model may change, defaulting to
  the Settings permissions.
- Send, progress and Cancel. Cancel stops the request; a late answer is discarded.
- The answer is shown as a proposal: a list of operations (add an object to layer L,
  change properties of object O, delete object O, insert a pixel image in layer L),
  with a preview overlay on the canvas. The designer applies all, applies a subset or
  rejects the proposal. Applying records one undo step. Nothing is ever applied
  automatically.
- Generated images returned by the provider are inserted as image layers (PNG with
  transparency) in the layer and frame the proposal names, after the same validation as
  imported images.

### API service

- Requests go from the AI Tools facade to the local API service, which holds the key and
  calls the provider (ADR-0037). The browser never calls the provider directly.
- The model can only answer through a fixed catalogue of operations described by a
  versioned proposal schema. Model output is untrusted data (SEC-0012): unknown
  operations, references outside the permitted scope, geometry beyond document limits
  and invalid images are refused per operation with a reason.
- An audit record per request keeps time, user, provider, model, attachment kinds,
  sizes and digests, operation counts and outcome, without prompt text or pixels.

## Illustrator parity

Illustrator CS3 has no equivalent to an external agent, so there is no behaviour or
shortcut to imitate and no default shortcut is assigned.

## Exclusions of this feature

The MCP bridge, per-tool grants with expiry, local or on-device models, autonomous
multi-step runs without approval, automatic application of results, streaming partial
proposals into the document, and any provider other than OpenAI in the first slice.

## Implementation and evidence

Implementing: the per-user token store, its API and the External tokens category of
Settings (SC-0148) are delivered with FEAT-0032 in 0.11.0. The panel, the provider requests,
the prompt library and the direct insertion of results (SC-0150 to SC-0154) are delivered in
0.12.0 on branch feat/agent-tools-panel. Not implemented: the Settings > AI Tools category
(enable switch, model choice, context and permission defaults, limits), the conversation, the
proposal flow with its operation catalogue (SC-0120, SC-0121), and a verified request against
the live provider, which needs the owner's token.
