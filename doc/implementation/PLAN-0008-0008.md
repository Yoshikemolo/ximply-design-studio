# Scaling, shearing, distorting and envelopes with the behaviour of Illustrator CS3

## Problem and acceptance

The studio scales with the Scale tool and the bounding box, rotates about a movable
pivot, reflects and repeats transformations, but it cannot shear, cannot distort freely or
in perspective, has no liquify tools and no envelopes. The owner asked for the sections
Scaling, shearing, and distorting objects and Reshape using envelopes of the Illustrator
CS3 Help to be followed, with their flow, modifiers and keys, and icons of our own drawn
in the spirit of the manual's. Oracles: [SC-0109](../sc/SC-0109.md) (Scale and Shear),
[SC-0110](../sc/SC-0110.md) (Free Transform), [SC-0111](../sc/SC-0111.md) (liquify tools)
and [SC-0112](../sc/SC-0112.md) (envelopes).

## Scope

- Scale tool: double-click or Object > Transform > Scale opens the Scale dialog, with
  Uniform or Non-Uniform percentages, Scale Strokes & Effects and Copy; Alt-click sets the
  reference point and opens it. Object > Transform > Transform Each (Alt+Shift+Ctrl+D)
  scales, moves and rotates each object about its own reference point (SC-0109).
- Shear tool, beside Scale and Reshape: a drag shears about the pivot, along the
  vertical axis when it starts up or down and along the horizontal axis when it starts
  sideways, Shift keeping the original width or height; a click moves the reference point
  first; double-click, Alt-click or Object > Transform > Shear opens the Shear dialog with
  the angle from -359 to 359, the horizontal, vertical or angled axis and Copy (SC-0109).
- Free Transform tool (E): its bounding box moves, scales (Shift for proportions, Alt from
  the centre), rotates from outside the box, shears when Ctrl+Alt is held while a side
  handle is dragged, distorts freely when Ctrl is held while a corner handle is dragged,
  and in perspective with Shift+Alt+Ctrl (SC-0110).
- Liquify tools: Warp (Shift+R), Twirl, Pucker, Bloat, Scallop, Crystallize and Wrinkle,
  with the brush drawn at the cursor, Alt-drag to size it and Shift+Alt for a circle, the
  options dialog on double-click with the ranges of the manual, and the selection limiting
  the objects they act on (SC-0111).
- Envelopes: Object > Envelope Distort > Make With Warp (Alt+Shift+Ctrl+W) with the Warp
  Options dialog and its styles, Make With Mesh (Alt+Ctrl+M), Make With Top Object
  (Alt+Ctrl+C), Release, Envelope Options, Expand, Edit Contents and Edit Envelope
  (Shift+Ctrl+V), Reset With Warp and Reset With Mesh; the mesh edited with the Direct
  Selection tool and the Mesh tool (U), whose click adds a row and a column and whose
  Delete on a chosen point removes them (SC-0112, ADR-0034 proposed).

## Contracts affected

- Native format 2 gains an optional `envelope` field on path layers that holds the
  enveloped objects, the mesh and the options (ADR-0034). The editor and the API
  validate it alike; earlier readers refuse documents that carry it.
- The command catalogue gains Free Transform (E), Warp (Shift+R), Mesh (U), Transform
  Each, Scale, Shear, the envelope commands and tools without keys (Shear, Twirl, Pucker,
  Bloat, Scallop, Crystallize, Wrinkle), as the manual gives them.
- Local settings keep the liquify options per tool and the Scale Strokes & Effects choice.

## Design

The geometry lives in the domain package, free of Angular and the canvas. `affine.ts`
applies any affine matrix to layers, decomposed into rotation, shear and size, so shear
on any axis and non-uniform scale keep every kind of object editable. `distort.ts` maps
paths through a quadrilateral with a projective map, which keeps straight lines straight,
after subdividing their segments. `liquify.ts` moves anchors and handles inside an elliptical brush with the
falloff of each tool and adds anchors where the tool needs them. `envelope.ts` holds a
mesh of Coons patches bounded by cubic edges, builds it from a warp style, a grid or the
outline of an object, and maps enveloped paths through it at the envelope's fidelity.
Envelopes are regenerated for drawing and export as procedural objects are, so the
canvas, SVG and PDF draw the same distorted paths.

## Risks and mitigations

- Non-affine maps bend straight segments; segments are subdivided before mapping, with
  the count set by the fidelity, and the result is checked against the exact map at
  sampled points.
- Mesh edits can fold a patch over itself; the mapping stays defined, and Release gives
  back the original objects untouched.
- A new layer kind in the native format breaks reading in earlier versions; the release
  note says so with its migration, and ADR-0034 waits for the owner.

## Divergences from Illustrator

- Free distort and perspective, the liquify tools and envelopes reshape vector paths:
  rectangles and ellipses become paths; text, images, symbols, dimensions and floor-plan
  objects are left out of free distort and perspective and named; text must be outlined
  (Ctrl+Shift+O) before it is enveloped, since the fonts are read by the application.
- The Free Transform tool also offers the Free Distort and Perspective Distort modes of
  its widget in later Illustrator versions, so a corner can distort without Ctrl; in
  Free Transform mode a corner scales, as in CS3.
- The Free Transform box is the bounds of the selection on the page axes, and it is
  not kept turned after a rotation; the cursor does not change with each mode.
- Zoom presets stop at the range the editor draws at, 10 to 300 percent, where Illustrator
  goes from 3.13 to 6400 percent; the canvas is drawn at the resolution of the document.
- The liquify tools read the pointer only: Use Pressure Pen is not offered.
- Envelope Options offers Fidelity only: the raster, appearance, gradient and pattern
  options have nothing to act on here, since rasters are not enveloped and gradients and
  patterns keep their own box.
- The Mesh tool edits envelope meshes only; gradient meshes are not implemented.
- Warp styles are drawn by the formulas this project defines for each named style, so
  their curves resemble but do not reproduce Illustrator's exactly; a warp is kept as a
  six by six mesh, which the Direct Selection tool edits point by point, where Illustrator
  shows one patch with its handles.
- The Envelope Options raster, appearance, gradient and pattern choices are not offered;
  gradients and patterns keep their own box inside the distorted shapes.

## Evidence

Recorded per checkpoint in the scenarios and in the release note.

## Rollback

Every tool and command is additive. Reverting the release commits restores the earlier
editor; documents that carry an envelope must first be expanded or released, or kept,
before they are opened by the earlier version.
