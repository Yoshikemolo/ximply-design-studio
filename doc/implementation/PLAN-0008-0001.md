# Drawing workbench and configurable input

## Problem and acceptance

Extend the local editor with editable cubic paths, construction primitives, path
refinement, tracing and reusable symbols. Improve direct manipulation without moving
browser chrome or losing text-editing behavior. The [roadmap](../planning/drawing-roadmap.md)
keeps incomplete fidelity visible.

| Requirement | Acceptance oracle |
| --- | --- |
| Cubic Pen and anchor editing | Independent cubic midpoint/subdivision identities; controls and subpaths survive history, native/API round trips and SVG export |
| Transform families | Rotate, Reflect and Scale families expose sibling tools in triangular flyouts; outside interaction and Escape close them; numeric controls operate on the selected group |
| Reflection | Optional flipX/flipY flags round-trip and affect vector, image and text rendering, hit tests and SVG output consistently |
| Corner, edge and rotation handles | Rotated opposite anchors stay fixed; edge handles change one local dimension; rotation handle changes angle about the center |
| Shift constraints | Configured angle in 1–90 degrees, default 45; linear motion and rotation snap while Shift is held; releasing Shift restores free motion |
| Keyboard preferences | Normalized chords and aliases are globally unique; collision prevents save; malformed persisted settings recover visibly; input/IME events do not trigger drawing commands |
| Discoverable commands | Menu actions show their current shortcut at the right; tooltips show tool name and current shortcut; updates reflect remapping |
| Inline text | Text tool over existing text edits that object's content in place; commit and cancellation preserve undo semantics |
| Canvas zoom | Ctrl+Space+wheel changes canvas scale only; consumed gesture prevents page zoom and leaves UI dimensions unchanged |
| Cursor badge | Current tool icon appears at cursor's lower-right; setting disables badge; overlay does not intercept pointer input |
| Dismissal | Outside interaction closes open custom dropdowns and menus without blocking the clicked target |
| Primitives and refinement | Known shape bounds/topology; cuts, joins and erasure remain vectors; rejected or canceled gestures do not damage history |
| Arrange and combine | Multiple selection; nested group/ungroup capped at depth 16; six alignment directions and two distribution axes; vector-only boolean area/topology checks and undo |
| Tracing and symbols | Known bitmap regions; source retention; linked definition edits; independent instance transforms and native round trips |

## Scope and boundaries

Domain geometry remains framework-free. Canvas and SVG consume editable cubic data.
Angular facades own state and history; input settings have a separate local version.
The existing backend validates new native data without changing authentication or
transport. [ADR-0023](../adr/ADR-0023.md) remains proposed, including the exact-pinned
polygon-clipping dependency for bounded filled-vector erasing.

Current approximations: tracing at 64 pixels per side; curved filled erasure sampled
at 24 points per segment; fixed 25 percent nine-slice inset; initial symbol styling.
Multi-object nonuniform scaling uses centered shear to preserve the world-space
geometry of rotated children. Familiar tool names do not assert complete behavioral
equivalence.
Contour fitting, registration/slice-guide editing and full graphic styles remain
pending. See the roadmap before describing the complete drawing scope as delivered.

## Failure, migration and rollback

Native format 2 adds curves, subpaths, symbol metadata and optional groupPath arrays
with at most 16 entries, plus optional flipX/flipY booleans and finite skewX degrees. Format 1 imports are
supported; new saves use format 2. Earlier readers cannot open those new files.
Preserve originals before migration; do not overwrite the only v1 copy. PNG/SVG are
interchange exports, not substitutes for a complete editable native project.

Tool defaults change: M rectangle, L ellipse, P Pen, N Pencil, Shift+E Eraser and
R Rotate, O Reflect, S Scale, Z Zoom, Ctrl/Cmd+G Group and Ctrl/Cmd+Shift+G Ungroup. Review Settings before relying on earlier temporary bindings. Conflicting
chords are not saved; browser-reserved shortcuts are bounded by browser behavior.

Reject malformed geometry, unknown versions and excessive counts. Keep operations
bounded and undoable. Rollback requires the earlier application and original v1
files; reverting code does not downgrade saved v2 files or stored server artifacts.

## Preview feedback cadence

Publish each coherent, tested user-visible batch on the feature branch with a unique
preview version and Markdown release notes. The first drawing checkpoint is
0.3.0-alpha.1 because native format 2 changes compatibility. Subsequent compatible
feedback patches increment the patch version, beginning with 0.3.1-alpha.1. Do not
reuse a published version or describe a preview checkpoint as a passing product gate.
Keep source revisions and actual test/CI results in the PR. Feedback patches remain
on the feature branch until all integration requirements are met.

Local acceptance sequence for this checkpoint:

1. Open Try an example. Confirm the editable cubic brand mark and vector studies.
2. Select Pen (P), click-drag points to draw curves, close by clicking the first
   anchor. Use Direct Selection (A) to edit anchors and handles.
3. Shift-click two overlapping shapes. Try each boolean operation and Undo after
   each result. Confirm subtract follows bottom-to-top stacking.
4. Group with Ctrl/Cmd+G; move, rotate and resize the group. Ungroup with
   Ctrl/Cmd+Shift+G and confirm children remain editable.
5. Drag a side handle and verify the opposite side stays fixed; drag the rotation
   handle. Hold Shift to apply the configured angle constraint.
6. Hold Ctrl while using Pen: Selection should be temporary and release should
   restore Pen. Ctrl+Space+wheel should zoom only the canvas.
7. Change a shortcut in Settings, attempt a collision and confirm it is rejected.
   Check updated menu labels/tooltips and reload to verify saved preferences.
8. Save, reopen and compare the project; report the preview version, operating
   system, browser and the shortest reproduction steps for any discrepancy.
