# First local vector and raster editor

## Outcome and scope

A runnable local Angular editor: rectangle, ellipse, freehand vector path and text,
selection/move/resize/rotation, editable layer visibility/locking/opacity/order,
undo/redo, image import, brush/eraser, image brightness/contrast/saturation/blur,
native editable document save/open and PNG/SVG export. Light/dark themes and EN/ES
labels use centralized assets/styles. About reads the versioned Markdown bundle.

A FastAPI service provides health and bearer-protected document storage through a
repository port. The local file adapter stores document artifacts only; it does not
replace the planned PostgreSQL/TypeORM transactional service. This first distribution
is a single-user local preview, not production IAM or multiuser collaboration.

## Boundaries and acceptance

Pure TypeScript document commands and geometry stay outside Angular and Three.js.
Angular facades own signals; Canvas2D is the first 2D renderer. Optional spatial
inspection projects layers with Three.js. Native files round-trip editable data;
PNG export is flattened by definition. Validate input size, finite geometry and
allowed entity/tool types. No arbitrary SVG/HTML import or plugin code execution.

Tests cover independent geometry, transforms, selection, history, document validation,
export escaping and backend authentication/path traversal. Build and local smoke
checks must succeed. Release notes distinguish working capabilities from planned
professional features, including color management, PSD/AI fidelity and collaboration.

## Risks, migration and rollback

Raster data URLs increase history memory; bound image dimensions and history length.
Use a versioned native format and reject unknown versions. Artifact writes are atomic.
Local API credentials come from an environment secret and are entered by the user;
never embed them into the frontend bundle. Browser-only save/open works without API.
Docker publishes only on loopback. Do not expose the preview as production.

## Delivery

Implement domain/renderer, then shell and tools, then API and packaging. Validate
