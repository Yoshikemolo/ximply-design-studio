# Appearance, measurement aids and guide layers

## Problem and acceptance

Expose the same fill/stroke picker from the context bar and overlapping tool-rail
swatches, including no paint, black, white, color and stroke width. Swap fill/stroke
without losing the selected target. Move theme switching beside the locale selector.
Split the context bar into independently visible persisted View > Layout blocks.

Distance and font units must affect displayed dimensional values and editing across
the interface without rescaling document geometry. Use px, pt, mm, cm, in and ft with
96 px per inch and 72 points per inch. These are document units, not a claim about
physical monitor calibration. Rulers and grid respond to canonical sizes, zoom and
scroll. Each of rulers, guides and grid has separate visibility, snapping and radius.

Drag from a ruler to create a horizontal or vertical guide as an editable layer.
Guide dragging moves it; releasing outside the artboard deletes it. Cancel restores
the prior document. Hidden/locked guides do not accidentally intercept drawing.
Layers can be reordered with group identity/order kept consistent. Guides are editing
aids and must never appear in artwork export.

## Scope and contracts

Domain measurement helpers own conversion, bounded tick generation and snapping.
All stored geometry remains pixels. Snap tolerances are CSS pixels divided by zoom.
Preference changes do not resize artwork. The optional native-v2 path layer `guide`
field is either vertical or horizontal; position uses x or y respectively. Guides
cannot be symbol definitions or grouped/symbol-linked artwork. Paint accepts the
explicit literal none or hex8 RGBA in fill/stroke, while the document background remains hex.
Frontend and authenticated API validators must agree on acceptance and rejection.
Renderer skips guides and skips canvas fill/stroke operations for absent paint.
Shared picker and overlay UI stay independent of export rendering. No dependencies,
transport changes or production service changes are introduced. See the proposed
[contract decision](../adr/ADR-0024.md).

## Acceptance oracles

- 25.4 mm and 1 inch both equal 96 px; 72 pt equals 1 inch. Unit changes preserve
  the exact stored coordinates, font sizes and stroke widths until edited.
- Missing/invalid preference values recover predictably; failed saves do not mutate
  the live setting. Ruler/grid generation remains bounded for tiny steps/large zoom.
- Independent snap settings select the nearest eligible coordinate only within the
  configured screen-space radius. Hidden aids do not snap, and no eligible target
  leaves the original point unchanged.
- No-color vector/text pixels stay transparent where neither fill nor stroke paints.
  SVG represents absent paint explicitly. Native/API roundtrips preserve guide and
  color state; malformed fields and incompatible native-v1 data are rejected.
- Guide creation, movement, outside deletion, cancellation and layer reorder have
  coherent undo/redo. Hidden/locked guides and grouped layer order have tests.
- Shared picker actions and all dimensional inputs route to canonical values;
  changing units is display-only. Rulers/guide overlays follow viewport coordinates.

## Sequence and documentation impact

Implement model/API/render contracts and pure measurement/preferences in parallel.
Integrate editor history, guide operations, layer ordering and snapping. Integrate
shared appearance controls, global unit displays, measurement overlays and layout.
Publish tested checkpoints with versioned Markdown notes and explicit branch/SHA.
Update feature traceability, generated navigation and bundled release metadata.

## Failure, migration and rollback

Existing files retain geometry and default to no guide metadata. New none paints and
guide metadata are native-v2 extensions that older readers may reject or fail to
preserve. Migration: retain original files and use this application version for new
saves; reverting application code does not convert files. Exporting SVG/PNG omits
editing guides and is not a substitute for the editable native document.
Pointer cancellation restores the previous document; outside release deletes only
the actively dragged guide. Grid/ruler settings must be finite and positive, and
rendered tick/line counts are bounded. Keep current quality gates unchanged.

## Validation and handoff

Record actual frontend/API/engineering tests, production build and packaged CI at
the checkpoint. Browser visual acceptance, strict Sonar evidence and required human
review remain distinct from feature-branch preview availability.

Independent paint alpha is separate from layer opacity. The shared picker preserves
RGB when editing alpha and preserves alpha when editing RGB. Native/API roundtrips
retain each channel; Canvas and SVG alpha combine with overall layer opacity.

## Contextual action follow-up

Capture target identity and revision for right-click menus on canvas, guides and
layer rows. Arrange complete sibling blocks within their parent; never flatten or
cross group ownership. Node actions preserve opposite handles unless converting
smoothness, and disabled/locked/stale targets reject mutations. Native editing-field
menus remain available. Validation covers group boundaries, stale node indices,
undo, keyboard navigation, dismissal and pointer coordinate routing. No native/API
changes or migration are needed. Revert the component/service patch to roll back.
