# Contextual grouping and editable vector dimensions

## Problem and acceptance

Retain multiple selection when opening its context menu. Offer Group, Ungroup and
Regroup according to selected membership. Ungroup all selected groups without
modifying independent objects; regroup from a remembered member while retaining
subsequent object edits. A selected nested group removes only its own level; regroup
restores that level without losing its parent. Reject stale context targets and
unsafe locked mutations.

Create linear and angular dimensions with a default smart placement tool. Snap to
eligible singular points and show placement feedback. Reposition a dimension label
with its handle, edit formatting and typography, and transform annotation geometry
without deforming glyphs or endpoint markers. Expose visibility, locking and snapping
in a dedicated context block with localized icons and tooltips.

Provide independent line-start and line-end markers with an optional linked edit
mode. Expose separately configurable major and minor ruler intervals and snap
choices; render major ticks with labels and minor ticks without labels.

## Scope and design

Native-v2 adds path `dimension`, `lineEnds` and layer `regroupPath` metadata. Domain
and API validators must agree on finite bounds, enum values, shape and version
restrictions. Geometry remains pixels; units affect measurement formatting, not
artwork coordinates. Linear units include px, pt, mm, cm, in and ft. Angular values
are degrees. Formatting defaults carry forward to subsequent dimensions, while
existing dimensions retain independent values. Label overrides replace measured
text without modifying anchor geometry. Extension-line appearance is independent
from the dimension line. Canvas and SVG derive the same annotation geometry.

Dimension anchors are independent captured points, not persistent links to measured
objects. This slice excludes a CAD constraint solver, tolerances, radius/diameter,
chain/baseline annotations and full drafting-standard compliance. Dimension layers
are excluded from symbol creation and live blends. See [ADR-0028](../adr/ADR-0028.md).

Ruler intervals are local preferences. Existing major spacing is retained; a missing
minor interval migrates to one tenth of that spacing. The global ruler magnet gates
independent major/minor snapping. Tick-density reduction must not alter the stored
snap intervals. Both intervals share the existing screen-space ruler snap radius.

## Acceptance oracles

- Right-click inside multiple selection retains membership. Group/ungroup/regroup
  are atomic history actions. Unselected independent layers are unchanged.
- Native save/open retains regroup membership and subsequent object edits. Locked
  or incompatibly moved members cannot be silently regrouped.
- A 96-pixel linear span reports 1 inch at scale 1 and 2 inches at scale 2.
  Orthogonal angular arms report 90 degrees. Formatting changes never move anchors.
- Scaling, rotation and shear change measured geometry while glyphs and markers
  retain their configured shape and size. SVG and Canvas use the same endpoints.
- Linear placement captures two anchors, angular placement three; a further click
  places the label. Cancel abandons draft work. Label drag is one undoable operation.
- Hidden/locked annotation controls affect interaction consistently. Snapping uses
  bounded screen-space tolerance and excludes ineligible geometry.
- Start/end style edits remain independent when unlinked; linking applies matching
  edits. No markers are introduced on closed contours accidentally.
- Major/minor overlaps display one major tick; rendered tick counts remain bounded.
  Changing zoom or thinning visible ticks does not change snap spacing.
- API and native parsers reject malformed fields, unsupported layer combinations
  and native-v1 extensions; older unextended documents still load.

## Numeric transform follow-up

Expose Enter Displacement (Ctrl+Shift+M) and Enter Rotation (Ctrl+Shift+R) in the
contextual interaction flow (Cmd replaces Ctrl on macOS). Existing customized
shortcut collisions preserve the older command and leave the new command unassigned.
Apply numeric values to the selected object/group or
active Bezier anchors, using an explicit rotation center. Preserve undo boundaries
and locked-object guards. Final integration must verify shortcut collision handling,
localized dialogs, center coordinates and individual-anchor behavior; do not infer
these from whole-object transform support.

## Work sequence and documentation impact

Implement geometry/rendering, API validation, interaction and UI in parallel with
separate ownership. Integrate contextual actions and ruler preferences, then check
contracts, editor history, actual pixel/export behavior, UI build and documentation.
Register real code/test paths, regenerate navigation and changelog artifacts, and
publish a versioned feature-branch checkpoint with exact test and commit evidence.

## Failure and migration

Migration: preserve original documents before saving native-v2 extension data.
Older readers may reject or discard dimension, endpoint or regroup information.
Use this version or newer to edit these saves. Rendered exports preserve appearance,
not editable annotation semantics. Reverting application code is not a document
conversion. Ruler preference migration requires no native-document changes.

Validate finite numeric bounds before mutations. Cancel and failed validation must
not leave partial document edits or history entries. Dense intersection searches
must stay bounded; snapping does not promise every intersection in arbitrarily dense
artwork. Group metadata follows surviving objects, not a separate object snapshot.
