# AI Tools panel with an external provider

ID: PLAN-0029-0001
Status: Proposed
Owner: Yoshikemolo
Feature / scenarios / ADRs / SEC controls: FEAT-0029 / SC-0118 to SC-0122 / ADR-0037,
ADR-0015 / SEC-0004, SEC-0012

## Problem and acceptance

The designer cannot ask an external agentic model to change a document with control
over what it sees and what it may change. Intended behaviour is recorded in FEAT-0029.
Oracles: SC-0118 to SC-0122, using recorded provider answer fixtures and a contract-test
double of the provider port, never the live provider in automated tests.

## Scope and design

- Domain: the operation catalogue and scope check as pure functions; the serializer of
  the document context for a chosen scope.
- Contracts: a versioned `contracts/ai-proposal.schema.json` and new `/api/ai`
  endpoints in `contracts/openapi.json` (settings status, key set and remove, connection
  test, request, cancel).
- API service: provider port, OpenAI adapter, validation of every operation, audit
  record, key storage, bounded size, timeout and concurrency.
- Web: AI Tools facade with real and mock adapters sharing a contract suite; the right
  column tabs Properties, AI Tools and History; the AI header button replacing the
  Export button; the panel with context composer, scope, proposal list and canvas
  preview overlay; the Settings > AI Tools category; EN and ES catalogs; new icons.
- Uses the FEAT-0030 preview entry point for the canvas and selection images.
- Excluded: MCP, grants with expiry, other providers, streaming into the document.

## Divergences from Illustrator

Illustrator CS3 has no equivalent, so none apply and no shortcut is assigned. The Export
button leaves the header; Export stays in File > Export….

## Work sequence

1. ADR-0037 accepted on 2026-09-23. Deliver FEAT-0032 first, since the panel needs a licence.
2. Schema and domain catalogue with scope checks and adversarial unit tests (SC-0121).
3. API port, double, adapter and validation with contract tests (SC-0122).
4. Right column tabs and AI header button (SC-0118), then the panel and composer
   (SC-0119), then proposal preview and apply (SC-0120).
5. Settings category, documentation, threat model evidence and release notes.

## Failure and migration

No document format change. A failed or cancelled request leaves the document unchanged.
Rollback is disabling AI Tools in Settings; the stored key can be removed.

## Validation and handoff

Domain, contract, API and UI tests, documentation checks, security review of the new
egress, and the strict quality profile. One key per installation, as the owner decided.
Open questions for the owner: the default model identifier; whether the Layers panel stays inside
the Properties tab; and the review of the provider's data terms before real use.
