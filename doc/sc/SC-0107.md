# SC-0107 — Gradient and pattern fills, patterns and swatches

Status: Implementing
Feature: FEAT-0008

## Gradient oracle
A linear gradient crosses the object's box along its angle: at 0 degrees it runs from
the left edge to the right edge, and at 90 degrees from the bottom to the top. A radial
gradient spreads from the centre to the farther side. A midpoint moved from 50 puts the
even mix of its two stops at that point between them. A line drawn with the Gradient
tool replaces the angle with its own start and end.

## Pattern oracle
A pattern tiles its artwork from the document origin, not from the object, so two
objects with the same pattern line up. A pattern the document does not hold leaves the
fill colour.

## Output oracle
The canvas and SVG paint the same gradients and patterns. A fill of None paints nothing
whatever paint the object carries.

## Format oracle
The `fillPaint`, `patterns` and `swatches` fields of native format 2 are validated by
the editor and the API alike, within the bounds of ADR-0033. Format 1 refuses them.
