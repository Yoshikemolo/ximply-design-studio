# SC-0129 — Merges and conflicts

Status: Implementing
Feature: FEAT-0031
Owner: Yoshikemolo

## Merge oracle

Merging a branch that is only ahead fast-forwards. Merging diverged branches without
conflicts records a merge commit with two parents whose tree equals the fixture's
expected tree.

## Conflict oracle

Merging branches that changed the same document lists the conflicting files. Choosing one
side for each resolves the merge and records a merge commit; aborting returns the branch,
the files and the open documents to the state before the merge. The editor never opens a
file that holds conflict markers, and no conflict is resolved without the designer's
choice.

## Evidence

Implemented with resolution by side and abort. Automated: services/api/tests/test_vcs.py (fast-forward and merge commit; conflicts listed, resolved by side or aborted) and apps/web/tests/change-control.test.ts (conflicted merge) on feat/change-control for 0.13.0. Human review, a security review of the Git runner and the paused Sonar analysis are outstanding.
