# SC-0121 — Out-of-scope or malformed model output

Status: Planned
Feature: FEAT-0029
Owner: Yoshikemolo

## Scope oracle

With the change scope limited to layer A, a proposal that changes an object of layer C,
deletes an object while deletion is not allowed, or references an unknown identifier has
those operations refused with a reason each; the remaining valid operations can still be
applied, and nothing is applied without the designer's action.

## Validation oracle

An operation outside the catalogue, a malformed schema, geometry beyond the document
limits, or an image that fails the imported image checks of SEC-0005 is refused. Text in
the document, the prompt or the model output that claims to grant permissions or to
change the scope has no effect on the scope that the API service enforces.

## Evidence

Not executed. This is an acceptance requirement, not a passing test report.
Required before Verified: test path and name, source revision, command, result artifact,
independent oracle and human review.
