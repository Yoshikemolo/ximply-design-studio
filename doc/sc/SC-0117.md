# SC-0117 — Paint layers cropped to what is painted

Status: Released
Feature: FEAT-0008

## Crop oracle
A Brush stroke on an empty page makes a paint layer marked `paintLayer`, as large as the
page while the stroke runs; when it ends, the layer is cropped to the painted pixels, and
drawing the cropped picture at the layer's frame gives the same pixels as the page-sized
buffer did. Undo removes the layer and redo restores the same picture.

## Growth oracle
A later stroke elsewhere on the page grows the paint layer to cover both strokes, and a
stroke past the edge of the page keeps the pixels outside it.

## Boundary oracle
A stroke that changes nothing, and a cancelled stroke, leave the selection and the redo
history as they were. A result beyond the limits of the document is refused and the
document is left unchanged. A paint layer erased completely is removed, and undo brings it
back. Placed pictures keep their frame when painted on. A turned or reflected paint layer is
baked upright without moving its pixels or changing its opacity.

## Format oracle
The editor and the API accept `paintLayer` only as `true` on an image layer of format 2 and
refuse it as null, false, a string or on another kind (ADR-0036, accepted).

## Evidence
Automated: apps/web/tests/paint-bounds.test.ts, apps/web/tests/editor.test.ts,
services/api/tests/test_api.py (the paint marker validation).
Owner review: the owner accepted this behaviour visually on 2026-09-22 for the maturity of
this preview and approved its status as Released, published in 0.9.0. The strict Sonar gate
is paused and outstanding, so it is not Verified.
