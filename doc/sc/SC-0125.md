# SC-0125 — Change control settings and repository setup

Status: Planned
Feature: FEAT-0031
Owner: Yoshikemolo

## Settings oracle

Settings lists a Change control category in the left column and shows only its form in
the right column. With change control disabled, the History tab explains how to enable it
and offers no operation, and the facade makes no change-control request.

## Setup oracle

Initializing a project directory inside the workspace root creates a repository with the
configured default branch, the project manifest and an initial commit by the configured
author. Opening an existing repository shows its current branch and history.

## Confinement oracle

A project directory outside the workspace root, or one reached through a symbolic link
that leaves it, is refused.
