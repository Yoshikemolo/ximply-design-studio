# SC-0123 — Selection converted to a transparent pixel image

Status: Implementing
Feature: FEAT-0030
Owner: Yoshikemolo

## Pixel oracle

Given a fixture of two overlapping filled and stroked paths selected, converting at
150 ppi produces a PNG whose size is the visible bounds of the selection, strokes
included, at 150 ppi, and whose pixels equal an independent golden image of the same
fixture within the recorded anti-aliasing tolerance. Pixels outside the art have alpha
0.

## Placement oracle

The image is inserted as a new image layer directly above the topmost selected object
in its parent, at the bounds of the selection, and is selected. The source objects are
unchanged. The conversion is one undo step; undo removes the image and restores the
selection, redo inserts the same image.

## Options oracle

The added margin enlarges the image by the margin on every side. Anti-aliasing none
produces only alpha 0 or 255. Every edge pixel covered only in part widens the frame by at
most one pixel. Cancelling the dialog
leaves the document unchanged.

## Evidence

Automated: packages/domain/tests/rasterize.test.ts (target choice, paint area, pixel grid,
limits, margin frame, in-memory crop and aliasing) and apps/web/tests/rasterize.test.ts (pixels against a golden
image drawn with the canvas API at 150 ppi, placement, group, margin, aliasing, whole document
against PNG export, refusals, the preview entry point, a single readback of the drawing and the shell wiring). Run with
`npx vitest run` on the feat/convert-to-pixel-image branch for 0.10.0; the full suite passed
(143 files, 997 tests). Human review and the paused Sonar analysis are outstanding.
