# SC-0123 — Selection converted to a transparent pixel image

Status: Planned
Feature: FEAT-0030
Owner: Yoshikemolo

## Pixel oracle

Given a fixture of two overlapping filled and stroked paths selected, converting at
150 ppi produces a PNG whose size is the visible bounds of the selection, strokes
included, at 150 ppi, and whose pixels equal an independent golden image of the same
fixture within the recorded anti-aliasing tolerance. Pixels outside the art have alpha
0.

## Placement oracle

The image is inserted as a new image layer directly above the topmost selected object
in its parent, at the bounds of the selection, and is selected. The source objects are
unchanged. The conversion is one undo step; undo removes the image and restores the
selection, redo inserts the same image.

## Options oracle

The added margin enlarges the image by the margin on every side. Anti-aliasing none
produces only alpha 0 or 255 on a shape without soft effects. Cancelling the dialog
leaves the document unchanged.

## Evidence

Not executed. This is an acceptance requirement, not a passing test report.
Required before Verified: test path and name, source revision, command, result artifact,
independent oracle and human review.
