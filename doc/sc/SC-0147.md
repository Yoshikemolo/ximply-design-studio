# SC-0147 — Super administrator access and the advanced tools block

Status: Planned
Feature: FEAT-0032
Owner: Yoshikemolo

## Access oracle

A token with `xds-admin` and no licence is allowed on the AI Tools and change-control
licence checks, and its session reports both permissions with the state unrestricted. A
token without `xds-admin` and without a licence is refused as before. The role is read only
from the verified token.

## Block oracle

The tool rail shows a separate block with AI Tools and Change control in every mode. In
demo mode, signed out or without the permission, each entry is shown as unavailable with
the reason from the session. When the user may use it, choosing it reports in the status
line that its panel is under development, until FEAT-0029 or FEAT-0031 delivers it.

## Evidence

Not executed. This is an acceptance requirement, not a passing test report.
Required before Verified: test path and name, source revision, command, result artifact,
independent oracle and human review.
