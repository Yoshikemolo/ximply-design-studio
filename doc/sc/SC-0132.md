# SC-0132 — Confined repository operations and secret credentials

Status: Planned
Feature: FEAT-0031
Owner: Yoshikemolo

## Injection oracle

Branch names, commit messages, remote URLs and paths that carry option text such as
--upload-pack, shell metacharacters, or traversal such as ../ are refused or passed as
data; no request runs a command or reads or writes a file outside the project directory.

## Hook and content oracle

Repository hooks and configuration from a cloned remote are not executed. Documents from
a remote are validated by the native document checks before the editor opens them.

## Secrecy oracle

After a GitHub credential is stored, no API response, log line, repository
configuration, remote URL, commit or exported file contains it.

## Evidence

Not executed. This is an acceptance requirement, not a passing test report.
Required before Verified: test path and name, source revision, command, result artifact,
independent oracle and human review.
