# SC-0155 — A thumbnail kept with each commit

Status: Implementing
Feature: FEAT-0031
Owner: Yoshikemolo

## Storage oracle

Making a project and committing send a PNG picture of the visible artwork, at most 240 pixels
on its longer side and laid on the page colour, which the API stores in the commit as
`preview/thumbnail.png`; it travels with the commit when it is pushed. A commit made without a
picture keeps none, and a preview that is not a PNG under 600 KB is refused.

## Hover oracle

Resting the pointer on a node or a message of the history graph shows the thumbnail of that
commit beside it, fetched once and then kept; the details of a commit show it too. A commit
without a thumbnail shows its message only.

## Evidence

Automated: services/api/tests/test_vcs.py (each commit keeps a thumbnail of its document) and apps/web/tests/change-control.test.ts (fetches a thumbnail once per commit) on feat/change-control for 0.13.0. Human review, a security review of the Git runner and the paused Sonar analysis are outstanding.
