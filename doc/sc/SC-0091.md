# SC-0091 — SVG import as editable native layers

Status: Implementing
Feature: FEAT-0022

## Acceptance oracle
A rectangle declared at 10, 20 measuring 60 by 40 arrives as a closed path of that
position and size; a circle of radius 25 around 100, 50 spans 75 to 125 across. A
group that translates by 100, 50 and scales by two turns a 10 by 10 square into a 20
by 20 square at the translation and doubles its stroke width. A viewBox of 100 units
shown at 200 pixels doubles every coordinate.

## Path oracle
Every command of the path grammar is read as cubic geometry: a smooth continuation
mirrors the previous control point about its node, a quadratic apex gives controls two
thirds of the way to it, and a half circle written as an arc keeps every sampled point
at its declared radius from the centre, turning clockwise on screen for a positive
sweep flag.

## Appearance oracle
Three-digit hexadecimal, rgb and rgba notations and the common colour names become
native paints; a gradient or pattern reference falls back to the inherited paint and
is reported. The inline style attribute wins over the presentation attribute of the
same element.

## Safety oracle
A document type declaration is refused, so no declared entity is ever expanded.
Scripts and event handler attributes never reach a layer. Element and node counts and
the file size are bounded, and a file over a limit raises before any layer exists.
What the reader cannot represent is named in the status line instead of disappearing.

## Evidence
Automated: packages/domain/tests/svg-import.test.ts,
apps/web/tests/vector-import.test.ts (pending changes on 0.4.0). Visual browser
acceptance is pending.
