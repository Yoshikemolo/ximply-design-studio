# SC-0135 — Registration, sign-in and sign-out with PKCE

Status: Planned
Feature: FEAT-0032
Owner: Yoshikemolo

## Flow oracle

Sign in redirects to the realm's authorization endpoint with response type code, a
state value and an S256 code challenge whose verifier stays in the tab. The callback
exchanges the code with that verifier; a callback whose state differs is refused and
nothing is stored. The Keycloak page offers registration.

## Session oracle

Signed in, the header shows the user and the menu shows the licence state and its
permissions as the API reports them. Tokens are refreshed before expiry; a failed
refresh returns to demo mode with a message. Sign out ends the Keycloak session and
removes the tokens from memory and session storage. No token appears in documents,
exports, local storage or logs.

## Evidence

Not executed. This is an acceptance requirement, not a passing test report.
Required before Verified: test path and name, source revision, command, result artifact,
independent oracle and human review.
