# SC-0127 — Commit of project changes

Status: Planned
Feature: FEAT-0031
Owner: Yoshikemolo

## Commit oracle

After an edit to a document, Commit saves the documents in canonical form and records one
commit with the message and configured author, whose tree equals the saved files. A second
save without edits changes no file. Pixel resources are stored as separate files named by
their content hash.

## Refusal oracle

An empty message is refused. With nothing to commit, Commit is unavailable.

## Evidence

Not executed. This is an acceptance requirement, not a passing test report.
Required before Verified: test path and name, source revision, command, result artifact,
independent oracle and human review.
