# SC-0127 — Commit of project changes

Status: Implementing
Feature: FEAT-0031
Owner: Yoshikemolo

## Commit oracle

After an edit to a document, Commit saves the documents in canonical form and records one
commit with the message and configured author, whose tree equals the saved files. A second
save without edits changes no file. Pixel resources are stored as separate files named by
their content hash.

## Refusal oracle

An empty message is refused. With nothing to commit, Commit is unavailable.

## Evidence

Implemented for the single document of a project; choosing a subset of files is not. Automated: services/api/tests/test_vcs.py (canonical document, pictures stored once by hash, commits refuse nothing or no message) and apps/web/tests/change-control.test.ts (commits the linked document) on feat/change-control for 0.13.0. Human review, a security review of the Git runner and the paused Sonar analysis are outstanding.
