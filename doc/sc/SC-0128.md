# SC-0128 — Branch creation, renaming, deletion and checkout

Status: Planned
Feature: FEAT-0031
Owner: Yoshikemolo

## Branch oracle

Creating a branch at HEAD or at a selected node points it at that SHA. Renaming changes
its name and keeps its SHA. A name that Git refuses, or one that starts with a dash, is
refused with a message. Deleting the current branch is refused; deleting an unmerged
branch asks for confirmation.

## Checkout oracle

Checking out a branch or a commit with unsaved editor changes asks to commit, keep or
discard them first. After checkout the open documents equal the files of the checked-out
commit, and nothing unsaved is lost without the designer's choice.

## Evidence

Not executed. This is an acceptance requirement, not a passing test report.
Required before Verified: test path and name, source revision, command, result artifact,
independent oracle and human review.
