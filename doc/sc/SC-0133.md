# SC-0133 — Commit node context menu

Status: Planned
Feature: FEAT-0031
Owner: Yoshikemolo

## Menu oracle

A right-click, the context-menu key or Shift+F10 on a node opens a menu that lists only
operations valid for that node: on a node without branch labels it offers check out,
create branch here, revert, copy SHA and details; on a node that carries branch labels it
also offers merge into the current branch, rename and delete for those branches, except
delete for the current branch.

## Consistency oracle

Each menu action produces the same result as the matching toolbar action for the same
node, and Escape closes the menu without changes.

## Evidence

Not executed. This is an acceptance requirement, not a passing test report.
Required before Verified: test path and name, source revision, command, result artifact,
independent oracle and human review.
