# SC-0126 — Commit graph of branches and merges

Status: Implementing
Feature: FEAT-0031
Owner: Yoshikemolo

## Graph oracle

Given a fixture repository built by a script with a known topology of three branches,
one fork and two merges, the graph shows one node per commit in the topological order of
the fixture, one lane per branch, one edge per parent link, and the branch labels, HEAD
and remote badges at the SHAs the script recorded. The expected layout is an independent
fixture, not the output of the graph code.

## Status oracle

Ahead and behind counts equal those computed by the Git command line on the fixture.
Uncommitted changes show a working-copy node at the top; with none, the node is absent.
Selecting a node shows its message, author, date, SHA, parents and changed files.

## Evidence

Implemented without tags: packages/domain/tests/commit-graph.test.ts (history graph lanes), apps/web/tests/change-control.test.ts (graph rows with branches, HEAD and comment counts) and services/api/tests/test_vcs.py (log with local and shared branches, at most 400 commits) on feat/change-control for 0.13.0. Human review, a security review of the Git runner and the paused Sonar analysis are outstanding.
