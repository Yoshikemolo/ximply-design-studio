# SC-0151 — What a request carries, labelled

Status: Implementing
Feature: FEAT-0029
Owner: Yoshikemolo

## Selection oracle

With the selection as the context, the request carries the prompt, the selected objects as
data (pictures replaced by a marker, within 200,000 characters), a transparent PNG of the
selection made by the FEAT-0030 rasterizer, a PNG of the whole document for reference, and
the modifiers: the action and the creativity. The instruction the API gives the model labels
Image 1 as the selected objects and Image 2 as the whole document.

## Document oracle

With the whole document as the context, the request carries only the document PNG, the
prompt and the modifiers.

## Feedback oracle

While the request travels, the panel lists each part with its size, and the footer shows a
moving bar and the phase: capturing the context, sending it, waiting for the model and
inserting the result. Cancel stops the request and nothing is inserted.

## Evidence

Automated: apps/web/tests/agent-tools.test.ts (sending the context, cancel), packages/domain/tests/agent-result.test.ts (the selected objects as data) and services/api/tests/test_agent_tools.py (instruction labels, document scope) on feat/agent-tools-panel for 0.12.0. Human review, a request against the live provider with the owner's token and the paused Sonar analysis are outstanding.
