# SC-0120 — Proposal preview, apply and reject

Status: Planned
Feature: FEAT-0029
Owner: Yoshikemolo

## Preview oracle

Given a recorded provider answer fixture that adds a rectangle to layer A, changes the
fill of object O and inserts a PNG image in layer B, the panel lists three operations
and the canvas shows their preview without changing the document; the document
serialization is byte-identical to the one before the answer.

## Apply oracle

Applying all operations produces the objects and properties the fixture specifies, in
the named layers and at the named frames, as one undo step. Undo restores the
byte-identical document, and redo reapplies the same result. Applying a subset applies
only the chosen operations.

## Reject oracle

Rejecting the proposal leaves the document and its undo history unchanged.

## Evidence

Not executed. This is an acceptance requirement, not a passing test report.
Required before Verified: test path and name, source revision, command, result artifact,
independent oracle and human review.
