# SC-0124 — Whole document conversion and refused conversions

Status: Implementing
Feature: FEAT-0030
Owner: Yoshikemolo

## Document oracle

With nothing selected, the conversion covers every visible printing layer, is inserted
at the top of the layer stack, and its pixels equal a PNG export of the same area at the
same resolution. Hidden layers and nonprinting guide layers are not drawn.

## Refusal oracle

A conversion with no visible pixels, or whose pixel size exceeds the image limits of
the document, is refused whole with a message, and the document and history are
unchanged.

## Preview oracle

The programmatic entry point used by FEAT-0029 returns the same pixels as the inserted
image for the same input and resolution, and inserts nothing.

## Evidence

Automated: packages/domain/tests/rasterize.test.ts (target choice, paint area, pixel grid,
limits, margin frame, in-memory crop and aliasing) and apps/web/tests/rasterize.test.ts (pixels against a golden
image drawn with the canvas API at 150 ppi, placement, group, margin, aliasing, whole document
against PNG export, refusals, the preview entry point, a single readback of the drawing and the shell wiring). Run with
`npx vitest run` on the feat/convert-to-pixel-image branch for 0.9.3; the full suite passed
(143 files, 997 tests). Human review and the paused Sonar analysis are outstanding.
