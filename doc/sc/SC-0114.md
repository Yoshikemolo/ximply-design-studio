# SC-0114 — Gradient meshes

Status: Released
Feature: FEAT-0008

## Mesh tool oracle
A first click of the Mesh tool (U) inside a closed path or shape turns it into a gradient
mesh with the fewest mesh lines and a mesh point where it clicks, in the fill colour, or in
the colour already there with Shift; the other points keep the object's colour and the
object loses its stroke. A later click adds a row and a column through a new mesh point,
Alt-click on a mesh point deletes it with its lines, and a drag moves it with its handles.
Text and compound paths are refused.

## Colour oracle
With a mesh point chosen, the fill colour goes to that point. Across a patch the colour is
the blend of its four corners: half way between black and white corners it is #808080.

## Command oracle
Object > Create Gradient Mesh takes rows and columns from 1 to 50, the Flat, To Center or
To Edge appearance and a highlight from 0 to 100 percent of white: To Center at 100 percent
makes the middle point white and leaves the border in the object's colour.

## Output oracle
The canvas and SVG draw the mesh as facets covering the object; PDF writes a type 6 Coons
patch mesh with twelve control points and four colours per patch. The field is validated by
the editor and the API alike (ADR-0035); earlier versions refuse documents that carry it.

## Evidence
Automated: packages/domain/tests/gradient-mesh.test.ts, apps/web/tests/gradient-mesh-editor.test.ts,
packages/renderer/tests/gradient-mesh.test.ts (the colour of each point and no seams between facets),
services/api/tests/test_api.py (the gradient mesh round trip and contract).
Owner review: the owner accepted this behaviour visually on 2026-09-22 for the maturity of
this preview and approved its status as Released, published in 0.9.0. The strict Sonar gate
is paused and outstanding, so it is not Verified.
