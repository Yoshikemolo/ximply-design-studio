# SC-0145 — Licences with state and period

Status: Implementing
Feature: FEAT-0032
Owner: Yoshikemolo

## List oracle

The Licences category lists one row per user holding a licence record, with holder,
permissions, state, issue date and expiry, and can be searched, filtered and sorted.

## State oracle

Suspending a licence keeps its permissions and expiry but the API refuses the capabilities
with the reason suspended; resuming restores them. Changing the permissions or the expiry
takes effect from the next token of the user. An expired licence shows the state expired
whatever its stored state.

Automated, on the feat/sign-in-and-licences branch for 0.11.0: services/api/tests/test_identity.py
(token validation, forged and stale tokens, licence policy, super administrator, suspension),

issuing, extending and revoking licences, the administration workspace rendered with a real
administrator session in headless Chrome. Not verified: that the account console refuses a
user editing their own licence attribute, and any Keycloak on the published preview, which
has none. Human review and the paused Sonar analysis are outstanding.
