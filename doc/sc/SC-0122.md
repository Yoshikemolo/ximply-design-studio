# SC-0122 — Provider failure, cancellation and key secrecy

Status: Planned
Feature: FEAT-0029
Owner: Yoshikemolo

## Failure oracle

With the provider adapter replaced by a contract-test double, an authentication error,
a rate limit, a timeout and an unreachable network each produce a precise message in
the panel, leave the document unchanged and never produce a proposal from a mock or any
other provider.

## Cancel oracle

Cancelling a running request stops it; an answer that arrives after cancellation is
discarded and cannot be applied.

## Secrecy oracle

After a key is stored, no API response, log line, audit record, exported file, saved
document or project commit contains the key or a recoverable part of it. The audit record
of a request contains no prompt text or pixels.

## Evidence

Not executed. This is an acceptance requirement, not a passing test report.
Required before Verified: test path and name, source revision, command, result artifact,
independent oracle and human review.
