# SC-0142 — Creating, editing and deleting users

Status: Implementing
Feature: FEAT-0032
Owner: Yoshikemolo

## Create oracle

Creating a user with a username, email, names and an initial password creates the Keycloak
user, marks the password temporary when chosen, and grants the Administrator role only when
asked. A username or email already in use, or a password shorter than the realm policy, is
refused with the reason.

## Edit and delete oracle

Editing changes the email and names and keeps the licence. Deleting a user removes it from
Keycloak after confirmation. An administrator cannot delete, ban or remove the Administrator
role from their own account.

## Facts oracle

Each user shows the registration date from Keycloak, the last sign-in from the login events
of the realm (or none recorded within their retention), and the number of documents on the
server whose owner is that user.
