# SC-0140 — Branded Keycloak pages

Status: Planned
Feature: FEAT-0032
Owner: Yoshikemolo

## Branding oracle

The sign-in, registration, password update and error pages of the realm show the studio
logo block (the X mark, ximply in large type, design studio beneath) centred above the
form, in the light and dark schemes of the browser. The logo is served by the theme, not
fetched from another site, and the pages keep working without the studio running.

## Function oracle

Signing in, registering and updating a password through the themed pages behave as with
the default theme: the realm file selects the theme and nothing else changes.
