# SC-0152 — Saved and favourite prompts

Status: Implementing
Feature: FEAT-0029
Owner: Yoshikemolo

## Library oracle

Every user starts with eight default prompts. A user saves the current prompt, action and
creativity under a title; saving under a title that exists replaces that prompt and keeps its
favourite mark. Favourites come first, then the user's prompts, then the defaults. Defaults
can be marked favourite but not changed. Choosing a prompt loads its text, action
and creativity. The API keeps up to 200 prompts per user, only for that user.

## Search and removal oracle

A search box above the list keeps the prompts whose title, text or action contain every word
typed, ignoring case and accents, and reading titles and actions in the panel's language. Every
prompt has a red Remove button that asks for confirmation: the user's own prompt is deleted, and
a default is hidden from that user's list until Restore default prompts shows the defaults
again. A saved prompt keeps its result type.

## Failure oracle

When the server refuses to save, the list stays as it was and the panel says why.
