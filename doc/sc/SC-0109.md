# SC-0109 — Scale and Shear tools and dialogs

Status: Implementing
Feature: FEAT-0008

## Scale oracle
Double-click on the Scale tool, or Object > Transform > Scale, opens the Scale dialog about
the pivot; Alt-click with the tool moves the pivot there first. Uniform scales both axes by
one percentage; Non-Uniform takes a horizontal and a vertical percentage, negative values
reflecting. Scale Strokes & Effects scales the stroke weight by the square root of the
area factor. OK scales the selection, Copy scales a copy and leaves the original. A 200 by
100 box scaled 50 by 200 percent about its centre becomes 100 by 200 about the same centre.

## Shear oracle
The Shear tool shears about the pivot. A drag that starts up or down shears along the
vertical axis and one that starts sideways along the horizontal axis; Shift keeps the
original width or height. The Shear dialog takes an angle from -359 to 359 and a
horizontal, vertical or angled axis; a unit square sheared 45 degrees along the
horizontal axis about its bottom left moves its top edge by its height, and every object
stays of its kind, text and images included.

## Transform Each oracle
Object > Transform > Transform Each (Alt+Shift+Ctrl+D) scales, moves and rotates each
selected object about its own centre, with Copy.
