# SC-0150 — AI Tools panel choices and Generate

Status: Implementing
Feature: FEAT-0029
Owner: Yoshikemolo

## Panel oracle

A signed-in user whose licence includes `ai-tools`, or the super administrator, sees in the
AI Tools tab: the context (Selection, with the count of selected objects, or Whole
document), the quick actions (Change style, Reinterpret in a style, Rescale, Improve
quality, Remove watermarks, Clean the background, Remove an object, Convert to paths and
groups), the prompt, the saved prompts, the creativity slider from Precise to Creative, and
a footer that stays at the bottom of the column with Repeat and Generate. Anyone else sees
the reason and, when it applies, Sign in.

## Readiness oracle

Generate is unavailable, and the footer says why, when the prompt is empty for a free prompt,
Change style, Reinterpret in a style or Remove an object, or when the context is the
selection and nothing is selected. An empty document as the context sends nothing and says
that it has nothing visible to send. Ctrl+Enter or Cmd+Enter in the prompt generates.

## Evidence

Automated: packages/domain/tests/agent-prompts.test.ts (when a request can be sent) and apps/web/tests/agent-tools.test.ts (incomplete requests, empty document) on feat/agent-tools-panel for 0.12.0. Human review, a request against the live provider with the owner's token and the paused Sonar analysis are outstanding.
