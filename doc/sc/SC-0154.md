# SC-0154 — Provider requests through the API

Status: Implementing
Feature: FEAT-0029
Owner: Yoshikemolo

## Request oracle

`POST /api/ai/generate` requires a verified session whose licence includes `ai-tools`; it
validates the action, the scope, the creativity and each PNG (signature and 20 MB) before any
provider call, and answers 409 with the way to fix it when the user has no saved token.
Picture actions call the image edit endpoint, with `gpt-image-2.5-flare` unless
`XDS_OPENAI_IMAGE_MODEL` names another model, with every image and a transparent background
where the action needs one; a vector result calls the responses endpoint with `gpt-6-sol`, unless `XDS_OPENAI_TEXT_MODEL`
names another, and a temperature derived from the creativity when the model accepts one (SC-0157). At most four requests run at once.


## Model pool oracle

Each kind of request has a pool of models tried in order: for pictures `gpt-image-2.5-flare`,
`gpt-image-2.5-sunburst`, `gpt-image-2`, `gpt-image-1.5` and `gpt-image-1`; for drawings
`gpt-6-sol`, `gpt-6-luna`, `gpt-6-astra` and `gpt-4.1`. A comma-separated
`XDS_OPENAI_IMAGE_MODEL` or `XDS_OPENAI_TEXT_MODEL` replaces a pool. When the project of the token
cannot use a model (no access, a model it cannot see, or an organization to verify), the next is
tried; any other refusal, such as a missing credit or a rate limit, stops at once, since another
model would fail the same way and could spend credit. The model that answered is tried first for
that token next time. When no model of the pool is usable, the answer names them all. Test
connection names the model of each pool the project will use.

## Secrecy oracle

The user's own token is decrypted only for the call. The audit record keeps the action, the
scope, the sizes and the outcome, never the prompt or pixels. Provider failures are explained:
a refused token, an account without API credit (`insufficient_quota`), too many requests per
minute (`rate_limit_exceeded`), any other rate or quota limit with OpenAI's own message, a
refused request with its reason, and an unreachable provider. The connection test of Settings
only lists the models, which OpenAI allows without credit, so it cannot detect a missing
credit.

## Evidence

Automated: services/api/tests/test_agent_tools.py (access, validation, provider requests, failures, audit) on feat/agent-tools-panel for 0.12.0. Human review, a request against the live provider with the owner's token and the paused Sonar analysis are outstanding.
