# SC-0153 — The result is inserted as a new object

Status: Implementing
Feature: FEAT-0029
Owner: Yoshikemolo

## Picture oracle

A picture the model returns is inserted as a new image layer, fitted into the frame of the
selection (its visual bounds) or of the page, keeping its proportions and centred, above the
topmost selected object and outside every group, as SC-0149 places converted pictures. It is
selected, nothing else changes, and one undo removes it.

## Drawing oracle

For Convert to paths and groups the model returns SVG, which is screened (no scripts, event
handlers or javascript links, at most 2,000,000 characters) and imported as editable paths
and groups fitted into the same frame, as one undo step.

## Repeat oracle

Repeat sends the last request again with the same context and choices and inserts another
result, even after the panel's choices changed.

## Evidence

Automated: apps/web/tests/agent-tools.test.ts (inserting the result) and packages/domain/tests/agent-result.test.ts (placing what the model returns, picture size) on feat/agent-tools-panel for 0.12.0. Human review, a request against the live provider with the owner's token and the paused Sonar analysis are outstanding.
