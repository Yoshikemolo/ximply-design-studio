# SC-0146 — Documents and owners

Status: Planned
Feature: FEAT-0032
Owner: Yoshikemolo

## Owner oracle

A document saved to the server by a signed-in user records that user as its owner; a
document saved with the local API token alone has no owner. The owner is never taken from
the document body.

## Administration oracle

The Documents category lists the stored documents with name, owner, size and last change,
searchable, filterable and sortable. Deleting one after confirmation removes it from the
store and the list; the count of documents of its owner decreases.
