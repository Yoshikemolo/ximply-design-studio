Status: Planned

## Catalogue oracle

The Roles and permissions category lists Administrator, `ai-tools` and `change-control` with
their descriptions and member counts that equal the users holding each role.

## Membership oracle

Adding a user to a role grants it in Keycloak and removing it revokes it; granting a
permission role does not create or extend a licence expiry, so it has no effect until the
user also holds a valid licence.
