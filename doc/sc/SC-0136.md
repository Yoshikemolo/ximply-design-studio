# SC-0136 — Advanced requests need a valid licence and permission

Status: Planned
Feature: FEAT-0032
Owner: Yoshikemolo

## Licence oracle

With tokens signed by a test key: a licence expiring tomorrow with `ai-tools` is allowed
on an AI Tools endpoint and refused on a change-control endpoint; a licence that expired
a second ago, a licence with no expiry, and a token without the permission are refused
with 403 and the reasons expired, no licence and permission missing.

## Token oracle

Tokens with a wrong issuer, a wrong audience, an expired `exp`, the `none` algorithm, an
HMAC signature, an unknown key identifier or a modified payload are refused with 401. A
licence claimed in a request body or header other than the token has no effect.

## Evidence

Not executed. This is an acceptance requirement, not a passing test report.
Required before Verified: test path and name, source revision, command, result artifact,
independent oracle and human review.
