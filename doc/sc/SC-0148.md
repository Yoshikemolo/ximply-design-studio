# SC-0148 — Each user's own OpenAI API token

Status: Planned
Feature: FEAT-0029
Owner: Yoshikemolo

## Ownership oracle

A user with the agent tools permission, or the super administrator, stores a token and sees
only that one is configured and when; another user, the super administrator included, sees
their own state and never the first user's token. The connection test uses the token of the
user who asks. Without the permission, or signed out, the category is absent and the API
refuses with the reason.

## Secrecy oracle

The token is encrypted at rest; no API answer, log, audit record, document or export holds
it or a part of it; a store with another service key cannot read it; without a service key
the API refuses to store tokens.

## Evidence

Not executed. This is an acceptance requirement, not a passing test report.
Required before Verified: test path and name, source revision, command, result artifact,
independent oracle and human review.
