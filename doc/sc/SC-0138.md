# SC-0138 — Issuing, extending and revoking licences

Status: Planned
Feature: FEAT-0032
Owner: Yoshikemolo

## Issue oracle

Issuing a licence with `ai-tools` for 30 days on 2026-09-23T10:00Z writes
`xds_licence_expires` 2026-10-23T10:00Z and assigns only that client role; issuing with
an explicit date writes that date at the end of its day in UTC. A date in the past or no
permission is refused.

## Extend and revoke oracle

Extending by 10 days adds them to a future expiry, or to now when it already expired.
Revoking removes the expiry and both permission roles. The next token of the user carries
the new state, and the API decides by it.

## Audit oracle

Each change writes one audit record with administrator, user, change and time, and no
token or secret.

## Evidence

Not executed. This is an acceptance requirement, not a passing test report.
Required before Verified: test path and name, source revision, command, result artifact,
independent oracle and human review.
