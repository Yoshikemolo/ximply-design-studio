# SC-0130 — Pull, push and fetch with a GitHub remote

Status: Implementing
Feature: FEAT-0031
Owner: Yoshikemolo

## Remote oracle

Against a disposable test remote, push publishes the current branch, fetch updates the
remote badges, and pull with the fast-forward only strategy updates a branch that is
behind. With the merge strategy, a diverged pull records a merge commit or reports
conflicts as in SC-0129.

## Failure oracle

A rejected non-fast-forward push, an invalid credential and an unreachable remote each
report a precise message and leave local branches, files and open documents unchanged.

## Evidence

Partly implemented: pull, push and fetch work against the shared repository on the server that every clone of the project uses, which is how several people share work in this slice. A GitHub remote waits for ADR-0040. Automated: services/api/tests/test_vcs.py (two people share work through the shared repository) on feat/change-control for 0.13.0. Human review, a security review of the Git runner and the paused Sonar analysis are outstanding.
