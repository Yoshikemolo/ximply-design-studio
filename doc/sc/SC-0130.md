# SC-0130 — Pull, push and fetch with a GitHub remote

Status: Planned
Feature: FEAT-0031
Owner: Yoshikemolo

## Remote oracle

Against a disposable test remote, push publishes the current branch, fetch updates the
remote badges, and pull with the fast-forward only strategy updates a branch that is
behind. With the merge strategy, a diverged pull records a merge commit or reports
conflicts as in SC-0129.

## Failure oracle

A rejected non-fast-forward push, an invalid credential and an unreachable remote each
report a precise message and leave local branches, files and open documents unchanged.

## Evidence

Not executed. This is an acceptance requirement, not a passing test report.
Required before Verified: test path and name, source revision, command, result artifact,
independent oracle and human review.
