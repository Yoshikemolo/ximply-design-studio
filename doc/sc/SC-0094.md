# SC-0094 — PDF export, printing and choosing documents

Status: Implementing
Feature: FEAT-0022

## File oracle
The written PDF opens with the version header and ends with the end of file marker,
declares a catalogue and a page tree, and every offset of its cross reference table
points at the object that declares itself there. A document of 400 by 200 pixels
becomes a page of 300 by 150 points, since a pixel is three quarters of a point.

## Drawing oracle
Shapes arrive as vector paths, not as a picture: a red square with a blue dashed
stroke writes its fill colour, its stroke colour, its width, its caps and joins and
its dash array, and its corners appear as the coordinates they have in the document.
The page is flipped once, because PDF measures upwards, and the text matrix flips back
so the glyphs stand upright. Transparency becomes one graphics state per value.

## Selection oracle
The export dialog opens with the current document chosen and lists every open tab. A
PDF collects the chosen documents into one file of one page each; SVG and PNG write
one file per chosen document. Printing writes one section per chosen document into the
printing window of the browser, and says so when that window is blocked. An export or
a print without documents is refused.

## Table oracle
The documents are listed by the shared table: each row carries the document name on
the left and its selection box on the right, with a tag for the current document. The
heading box chooses or clears every row and shows a mixed state while only some are
chosen. Every change of the selection is reported once, choosing the same row twice
does not repeat it, and an empty table is never all chosen.

## Reporting oracle
What the writer cannot represent is named: blend modes, images whose bytes could not
be prepared, strokes that are not centred, characters outside the Latin range, and the
fact that text is drawn with the standard font.

## Evidence
Automated: packages/domain/tests/pdf.test.ts, apps/web/tests/export-print.test.ts,
apps/web/tests/smart-table.test.ts
(0.5.0). Visual browser acceptance, and opening the result in a
third-party reader, are pending.
