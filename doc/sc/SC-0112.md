# SC-0112 — Envelopes

Status: Implementing
Feature: FEAT-0008

## Making oracle
Make With Warp (Alt+Shift+Ctrl+W) opens the Warp Options with a preview: the style among
fifteen, each shown by a picture drawn from its own formula, the horizontal or vertical
axis, Bend and the horizontal and vertical Distortion from -100 to 100. Make With Mesh (Alt+Ctrl+M) asks for rows and columns from 1 to 50. Make With Top
Object (Alt+Ctrl+C) uses the topmost selected path as the shape of the envelope. The
result is one object named Envelope that holds the originals. Text is refused with a
request to outline it first; pictures, symbols, dimensions and floor-plan objects are left out.

## Mapping oracle
The mesh is a grid of Coons patches bounded by cubic edges. An unedited mesh maps every
point to itself; a warp with Bend 0 and no distortion maps every point to itself; the
envelope of a top object maps the corners of the enveloped box to the extremes of that
object. The canvas, SVG and PDF draw the same distorted paths.

## Editing oracle
The Direct Selection tool drags mesh points and handles; the Mesh tool (U) adds a row and a
column through a click on an envelope, selected or not, and Delete removes those of a chosen point. Edit Contents
(Shift+Ctrl+V) edits the enveloped objects and Edit Envelope returns to the mesh. Reset
With Warp and Reset With Mesh replace the mesh, Envelope Options sets the Fidelity, Release
gives back the objects and the envelope shape, and Expand leaves the distorted paths.

## Format oracle
The envelope field of native format 2 is validated by the editor and the API alike
(ADR-0034); earlier versions refuse documents that carry it.

## Evidence
Automated: packages/domain/tests/envelope.test.ts (an unedited grid and a warp without bend
leave every point in place, a mesh sampled from a warp follows it within a pixel, a top
object takes the corners of the box, an added line keeps the shape within a thousandth of a
pixel, and the distortion follows the layer when it is moved or resized),
apps/web/tests/envelope-editor.test.ts, services/api/tests/test_api.py (the envelope round
trip and contract).
