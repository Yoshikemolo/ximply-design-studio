# SC-0112 — Envelopes

Status: Planned
Feature: FEAT-0008

## Making oracle
Make With Warp (Alt+Shift+Ctrl+W) opens the Warp Options with a preview: the style, the
horizontal or vertical axis, Bend and the horizontal and vertical Distortion from -100 to
100. Make With Mesh (Alt+Ctrl+M) asks for rows and columns from 1 to 50. Make With Top
Object (Alt+Ctrl+C) uses the topmost selected path as the shape of the envelope. The
result is one object named Envelope that holds the originals.

## Mapping oracle
The mesh is a grid of Coons patches bounded by cubic edges. An unedited mesh maps every
point to itself; a warp with Bend 0 and no distortion maps every point to itself; the
envelope of a top object maps the corners of the enveloped box to the extremes of that
object. The canvas, SVG and PDF draw the same distorted paths.

## Editing oracle
The Direct Selection tool drags mesh points and handles; the Mesh tool (U) adds a row and a
column through a click and Delete removes those of a chosen point. Edit Contents
(Shift+Ctrl+V) edits the enveloped objects and Edit Envelope returns to the mesh. Reset
With Warp and Reset With Mesh replace the mesh, Envelope Options sets the Fidelity, Release
gives back the objects and the envelope shape, and Expand leaves the distorted paths.

## Format oracle
The envelope layer of native format 2 is validated by the editor and the API alike
(ADR-0034); earlier versions refuse documents that carry it.
