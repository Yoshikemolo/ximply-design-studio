# SC-0097 — Illustrator and PDF drawing import

Status: Implementing
Feature: FEAT-0022

## Round trip oracle
A document exported by this editor and imported back returns the artwork it was made
of: a square drawn at ten, twenty measuring a hundred by fifty comes back at the same
pixels, with the same fill and no stroke, grouped under the name of the file. The page
box returns as the size the file declares, in pixels.

## Drawing oracle
A handwritten content stream is read as geometry: a filled and stroked triangle keeps
both paints and the width of its stroke, a curve inside a doubling transform arrives
twice its size, and a rectangle painted with no ink in any plate is white. The page is
turned upright, so a point ten units above the bottom of the page lands ten units above
the bottom edge of the document.

## Closing oracle
A path of three points painted with a fill arrives closed, since that is what filling
means; the same path painted with a stroke arrives open. Painted with both, it arrives
as two layers: the closed fill and the open stroke, so neither the shape nor the line
gains a segment it did not have.

## Colour oracle
One operand is grey, three are red, green and blue, and four are the printing plates:
cyan ink alone leaves green and blue, and full black leaves black.

## PostScript oracle
An encapsulated PostScript drawing is read with the names of the language and with the
aliases a drawing program defines for them, so the same triangle arrives whether it was
written with moveto, lineto and fill or with m, L and F. Colours arrive from setgray,
setrgbcolor, setcmykcolor and the colour words of the program, a stroked path keeps its
ends apart and its width in document pixels, and the transformations of the drawing are
followed. The words a program defines for itself, its prolog, are left out of the
drawing, the file is turned upright from its bounding box, and the PostScript of a file
that carries a preview is taken from where its header says it begins.

## Reporting oracle
Text, placed objects, inline images, gradients and clipping paths are named in the
status line and produce no layer. A file that is not a PDF, one with no page and a
page with no drawing are each refused with their own message, and the document is left
untouched.

## Evidence
Automated: packages/domain/tests/pdf-import.test.ts,
packages/domain/tests/eps-import.test.ts, apps/web/tests/vector-import.test.ts (0.5.0). A drawing of 250
paths exported from Illustrator and a logo of 95 objects exported from CorelDRAW as
encapsulated PostScript were imported by hand during development; visual
browser acceptance is pending.
