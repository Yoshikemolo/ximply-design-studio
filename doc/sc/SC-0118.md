# SC-0118 — AI Tools entry points and disabled state

Status: Planned
Feature: FEAT-0029
Owner: Yoshikemolo

## Shell oracle

The header shows an AI icon button where the Export button was, and File > Export…
still opens the Export dialog. Pressing the AI button shows the right column on the AI
Tools tab; pressing it again while that tab is shown hides the column. The right column
header shows the tabs Properties, AI Tools and History in that order, reachable by
keyboard with visible focus, with EN and ES labels from the catalogs.

## Disabled oracle

With AI Tools disabled in Settings, the AI Tools tab explains how to enable it and
offers no Send action, and the facade makes no request to the API service. With no key
configured, Send is unavailable and the panel names the missing setting.

## Settings oracle

Settings lists an AI Tools category in the left column and shows only its form in the
right column. Switching categories keeps saved values. The key field never shows a
stored key; it reports configured or not configured.

## Evidence

Not executed. This is an acceptance requirement, not a passing test report.

independent oracle and human review.
