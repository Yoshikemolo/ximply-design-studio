# SC-0119 — Context sent is exactly the context shown

Status: Planned
Feature: FEAT-0029
Owner: Yoshikemolo

## Payload oracle

Given a document with three layers and a selection, when the designer sends a prompt
with the serialized context and the selection image enabled and the canvas preview
disabled, the request recorded at the provider adapter boundary contains the prompt, the
serialized context and one image, and no canvas preview. The serialized context equals
an independently written fixture for the same document, and the selection image has the
same bytes hash as the FEAT-0030 conversion of the same selection at the capped
resolution.

## Scope oracle

When the designer limits the context to one layer, objects of other layers are absent
from the serialized context. Hidden layers and nonprinting guide layers are absent unless
the designer includes them explicitly. Every attachment listed in the composer shows its
size, and their sum equals the size of the request body minus the fixed envelope.

## Negative oracle

An attachment larger than the configured maximum is refused before sending, with a
message naming it; nothing is sent.

## Evidence

Not executed. This is an acceptance requirement, not a passing test report.
Required before Verified: test path and name, source revision, command, result artifact,
independent oracle and human review.
