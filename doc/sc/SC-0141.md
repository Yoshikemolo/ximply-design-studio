# SC-0141 — Administration workspace and smart tables

Status: Planned
Feature: FEAT-0032
Owner: Yoshikemolo

## Layout oracle

Admin opens a workspace with Users, Roles and permissions, Licences and Documents in the
left column and only the selected category on the right, with keyboard navigation between
categories as in Settings. It is absent for users without `xds-admin`.

## Table oracle

Given a fixed list of rows, the smart table's global search keeps the rows whose visible
text contains the term, a column filter keeps rows whose value in that column contains its
term, sorting by a column orders the rows by that value ascending then descending, and the
general sort choice gives the same order; the three combine. Paging shows the chosen page
of the filtered and sorted rows. The existing export list keeps its behaviour.

## Confirmation oracle

Deleting, banning, revoking and overwriting a password open an in-app confirmation that
names the subject and the consequence; cancelling sends nothing to the API.
