# SC-0089 — Painting controls and brush tips

Status: Implementing
Feature: FEAT-0010

## Acceptance oracle
Each brush tip stamps the shape it names: a round tip keeps both radii equal at any
angle, a flat and a calligraphy tip keep them different, and the tip angle turns the
stamp. Pressure, opacity, cadence and diffusion stay inside their declared ranges and
a value outside them is rejected instead of clamped silently. The eraser exposes
neither a blend mode nor a tip angle.

## Speed oracle
The speed variation slider runs from minus one hundred to plus one hundred with the
nominal size at zero. A positive setting makes a fast segment wider than a slow one
by the same factor the slider states, a negative setting reverses that relation, and
zero paints one constant width. The sample stroke of the control bar is stamped by
the same function as the canvas, so the preview and the paint agree.

## Zoom area oracle
A dragged rectangle of half the viewport doubles the zoom and centres on that
rectangle; a rectangle under eight pixels is ignored. Ctrl with Space and a drag does
the same while another tool is active.
