# SC-0095 — Clipboard, stacked pastes and the bounding box

Status: Implementing
Feature: FEAT-0007

## Paste oracle
A copied object pasted in front of a selected object keeps the coordinates it had and
lands immediately above that object in the stacking order; pasted behind, it lands
immediately below it. A plain paste offsets the copy by twenty units in each direction
and puts it on top of everything. The original never moves. Each paste is one history
step, and a cut followed by a paste is undone in two.

## Availability oracle
Nothing is pasted while the clipboard is empty, and nothing is copied or cut without a
selection. A locked object is not copied. The pastes, the copy, the cut, the duplicate
and the bounding box appear on the selected objects in the context menu, each with the
key that runs it. The tool rail carries them too, as a copy and paste group beside the
import action, where each one is enabled only when it applies: something selected to
copy, cut or duplicate, something copied to paste.

## Bounding box oracle
The frame, the eight handles and the rotation knob are drawn by default and disappear
together while the bounding box is hidden, which changes no artwork and is therefore
available even on a locked object.

## Key oracle
Copy is Mod+C, cut Mod+X, paste Mod+V, paste in front Mod+F, paste in back Mod+B,
duplicate Mod+D and the bounding box Mod+Shift+B.

## Evidence
Automated: apps/web/tests/clipboard.test.ts, apps/web/tests/context-actions.test.ts
(pending changes on 0.4.0). Visual browser acceptance is pending.
