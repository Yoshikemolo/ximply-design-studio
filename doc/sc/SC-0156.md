# SC-0156 — Comments on commits

Status: Implementing
Feature: FEAT-0031
Owner: Yoshikemolo

## Comment oracle

In the details of a commit, anyone who works on the project reads its comments and writes new
ones of up to 4000 characters; each shows its author and date. The graph shows how many
comments a commit has. A comment is removed by its author or the super administrator only.
Comments are kept on the server beside the repository and are not part of its history.

## Pull requests

Comments on pull requests are recorded as a requirement for when pull requests exist; pull
requests and review are excluded from this slice of FEAT-0031.

## Evidence

Automated: services/api/tests/test_vcs.py (comments on commits are shared and removed only by their author) and apps/web/tests/change-control.test.ts (adds a comment to the selected commit and counts it) on feat/change-control for 0.13.0. Human review, a security review of the Git runner and the paused Sonar analysis are outstanding.
