# SC-0137 — Admin menu only for administrators

Status: Planned
Feature: FEAT-0032
Owner: Yoshikemolo

## Visibility oracle

The Admin menu appears only when the signed-in user has the `xds-admin` role. Its users
list shows name, email, enabled state, licence expiry, permissions and state, with search
and paging, as the fake Keycloak port returns them.

## Authority oracle

Admin endpoints answer 401 without a token and 403 for a signed-in user without
`xds-admin`, whatever the browser shows. An administrator without a licence can
administer but not use the advanced capabilities.

## Evidence

Not executed. This is an acceptance requirement, not a passing test report.
Required before Verified: test path and name, source revision, command, result artifact,
independent oracle and human review.
