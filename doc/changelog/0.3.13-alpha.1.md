# 0.3.13-alpha.1 — Editable vector dimensions

## Breaking changes

- New native-v2 dimension, line-end and regroup metadata requires compatible readers. Migration: preserve original files and use this version or newer for new saves; SVG/PNG exports preserve visible annotations but not editable dimension semantics or regroup history.

## New features

- Add linear and angular dimension tools with singular-point placement assistance, editable measurement formatting and a movable label handle.
- Configure dimension scale, display units, decimal count and separator per annotation, carrying formatting defaults to subsequent dimensions.
- Add independent start/end markers: arrow, open arrow, triangle, dot, slash, cross or none, with size, tip/base placement and linked editing.
- Add Group, Ungroup and Regroup to contextual menus according to selection membership; retain edits and nested parent groups when restoring prior membership.
- Add numeric displacement and rotation entry for selected objects, groups and Bezier anchors with an explicit rotation center.

## Improvements

- Add dimension visibility, lock and snapping controls beside the existing measurement aids.
- Preserve annotation glyph and marker shapes during object transforms; customize dimension lines, extension lines and label typography.
- Configure major/minor ruler intervals and their snapping independently, while retaining the global ruler magnet and screen-space tolerance.

## Fixes

- Preserve multiple selection when opening its context menu and leave independent objects unchanged when ungrouping selected groups.

## Security

None.

## Engineering

- Validate dimension, endpoint and regroup extensions in native documents and API contracts; share annotation geometry between Canvas and SVG.
- Keep dimensions as independent captured annotations rather than persistent CAD constraints. Radius/diameter, tolerances and chain/baseline dimensions remain outside this preview.
- Migrate missing minor ruler preferences from the existing major interval without changing native artwork coordinates.
