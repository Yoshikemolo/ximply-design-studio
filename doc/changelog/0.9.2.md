# 0.9.2 — The web manifest served as JSON

A feedback patch on 0.9.1: the published manifest arrived as a plain download rather than
as JSON, because the host has no media type for the `.webmanifest` extension. It remains a
local preview: the strict quality gate is paused and outstanding.

## Breaking changes

None.

## New features

None.

## Improvements

None.

## Fixes

- Serve the web manifest, which lets a phone add the studio to its home screen, as JSON. The preview host returned it as `application/octet-stream`, since nginx knows no media type for the `.webmanifest` extension; the file is now `manifest.json`, which the host serves as `application/json`, a type the manifest specification accepts.
