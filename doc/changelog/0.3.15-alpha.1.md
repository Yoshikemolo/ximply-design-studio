# 0.3.15-alpha.1 — Document tabs, Clear and drafting-rule dimensions

## Breaking changes

None.

## New features

- Open several documents at once: New document and the tab strip plus button open a blank document in a new tab, and each tab keeps its own content, undo history and selection.
- Add File > Clear to empty the active document; it is undoable.
- Ask for confirmation in an in-app dialog before clearing or closing a document with unsaved changes.
- Close tabs individually; tabs show an unsaved-changes marker.

## Improvements

- Pre-mark the snap point of dimension tools with a small blue square on vertices, intersections, edge midpoints and points on edges.
- Preview the actual dimension while choosing its side and offset.
- Align linear dimension labels with the dimension line, never upside down, and break the line around the label when it fits.
- Move arrowheads outside and place the label beyond the nearest end when the space between extension lines is too small.
- Keep a gap between measured points and extension lines, overshoot the dimension line and draw 3:1 drafting arrowheads.
- Open projects in the current tab when it is an untouched blank document, otherwise in a new tab.
- Remove the redundant quick Fill, Stroke and Width rows from the tool rail; the overlapping fill and stroke squares keep the full appearance picker.

## Fixes

- Replace the native browser confirmation used by New document.

## Security

- Revalidate every restored local draft with the native document parser and bound local recovery to 12 tabs of 4 MB each.

## Engineering

- Store local recovery per tab and migrate the earlier single-document draft automatically.
- Share one dimension geometry between Canvas, SVG export, hit testing and the placement preview.
