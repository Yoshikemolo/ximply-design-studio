# 0.9.0 — Gradient meshes, a sharp magnified view and wide screen drawers

This release gathers what followed 0.8.0: gradient meshes made with the Mesh tool, a
magnified page drawn sharp with Pixel Preview beside it, the tools and panels as drawers on
wide screens, File > Save As, a reworked about screen and cropped paint layers, with fixes
to the Rotate tool, the light theme and the phone menu. The owner accepted the behaviour of
0.8.0 and of this release visually on 2026-09-22, except the cropping of paint layers,
which awaits review. It remains a local preview: the strict quality gate is paused and
outstanding, so the version number records delivered scope, not certified quality.

## Breaking changes

- Documents that hold a gradient mesh are refused by 0.8.0 and earlier editors and APIs, which do not know the field (ADR-0035, proposed). Migration: keep a copy, or remove the gradient meshes before opening the document in an earlier version.
- Documents that hold a paint layer made by the Brush carry the `paintLayer` marker, which 0.8.0 and earlier editors and APIs refuse (ADR-0036, proposed). Migration: keep a copy of the project for earlier versions; placed pictures are unaffected.

## New features

- Paint with gradient meshes. A first click of the Mesh tool (U) inside a shape turns it into a mesh whose new mesh point takes the fill colour, or keeps the colour there with Shift; later clicks add mesh points, Alt-click deletes one with its lines, and a drag moves one. With a mesh point chosen, the fill colour goes to that point. Object > Create Gradient Mesh makes a regular mesh with rows, columns, the Flat, To Center or To Edge appearance and a highlight. The colours blend across each patch on the canvas and in SVG, and PDF carries the mesh as a Coons patch shading. The Mesh tool also adds a row and a column to any envelope it clicks on, taking it without selecting it first.
- Show the artwork as its pixels with View > Pixel Preview (Alt+Ctrl+Y), as Illustrator does: one pixel per page unit, each a square when magnified. Snap to Pixel is not offered.
- Save a project under another name with File > Save As (Shift+Ctrl+S). Where the browser lets a page write to a file, its own dialog chooses the name and folder, the document takes that name, and later saves with Ctrl+S write to the same file instead of downloading a new one; elsewhere the name is asked for and the project is downloaded under it. The page writes only to the file chosen in that dialog.

## Improvements

- Draw a magnified page sharp. While the view pans, zooms or a gesture runs, the page is still drawn at one pixel per unit and magnified, which keeps it fast; once the view has been still for a moment, the part in view is drawn again at the screen's resolution, high pixel density screens included, and replaces it until the view moves again.
- Hide the tools or the panels on a wide screen as on a phone: View > Hide panels and Tools in View > Layout slide the column out to its side while the canvas widens, and a handle at that edge slides it back in over the canvas as a drawer. Unlike on a phone, the drawer stays open like a column while the canvas is used and tools are chosen, and its handle, then on its edge, slides it out again; showing the column again puts it back in place.
- Show or hide the context bar and the strip of document tabs from View > Layout, like the other blocks of the workspace; the canvas takes the height they leave, and the choice is remembered.
- Crop paint layers to what is painted. A Brush stroke paints on a frame that covers the whole page and keeps what goes past it, and when the stroke ends the layer keeps only its painted pixels, where they were; a later stroke grows it, a layer erased completely is removed, and a stroke that changes nothing leaves no undo step. Placed pictures keep their frame.
- Show in the about screen the logo, the name, the tagline "Create with precision feels simple", the version picker and the close button on one compact row, the licence the build carries with the SHA-256 of its LICENSE file on one line, and the credits of the footer with the links to LinkedIn, Ximplicity and GitHub in the same style. The head stays above the line and the credits stay at the foot, while only the release notes scroll between them; a screen under 560 pixels high scrolls as a whole. An empty page shows the brand of the header above its call to action instead of a blue x.
- Draw the minor ruler mark half way between two major ones longer than the other minor marks and shorter than a major one, so the middle of each interval is found at a glance.
- Lay out Snap to ruler ticks in Settings > Measurement with its Major and Minor switches side by side on one row, each beside its label and centred on the line of the neighbouring field.

## Fixes

- Turn the selection with the Rotate tool by the angle measured about its pivot, as Illustrator measures it about the reference point. The angle was measured about the centre of the object, so with the pivot elsewhere a pointer passing near the centre swung the object round the pivot and could carry it off the page; right at the pivot the angle now holds until the pointer is clear of it.
- Draw the icons of the active toggles of the context bar white on their blue background in the light theme, where they were dark, as they already were in the dark theme.
- Keep the name of the page just above it, and above the rulers when they are shown; it was placed against the corner of the work area, where the rulers covered it once the page was larger than the view.
- Open the menus from the menu button on a phone: a tap on File, Edit, View, Object or Help reached the backdrop of the drawers, drawn above the header, and the menu never unfolded. Every dialog, popover, list of tools and context menu fits the screen of a phone upright or on its side, scrolling where it is taller.
- Close the appearance popover with a press anywhere outside it, as the list of a tool family closes; while the colour picker's eyedropper takes a colour from the page, the popover stays open. Several listeners of the page for the same press were not all called, so the popover never closed.
- Cover the seams between the facets of a gradient mesh, which let the background show through as thin lines.

## Engineering

- Draw a region of the page at any scale with the canvas renderer, which the sharp view uses, and keep the computation of the visible region in the domain package, tested against numeric oracles.
- Record the gradient mesh field of the native format as ADR-0035 and the paint layer marker as ADR-0036, both proposed and awaiting owner review, and the scenarios SC-0114 to SC-0117; the editor and the API validate both fields alike.
