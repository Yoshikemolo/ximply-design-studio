# 0.13.1 — Precise reasons for provider limits

A feedback patch on 0.13.0. It remains a local preview: the strict quality gate is paused and
outstanding.

## Breaking changes

None.

## New features

None.

## Improvements

None.

## Fixes

- When OpenAI refuses a generation with a rate or quota limit, the panel now says which: the account of the token has no API credit left, or it made too many requests per minute; any other limit shows OpenAI's own message. Before, every case showed the same generic text, which suggested the prompt was too long.

## Security

None.

## Engineering

- SC-0154 records the refusal reasons and that the connection test cannot detect a missing credit.
