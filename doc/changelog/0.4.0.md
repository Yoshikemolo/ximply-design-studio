# 0.4.0 — Multi-document workbench and construction tools

This release collects the preview notes 0.3.15-alpha.1 and 0.3.16-alpha.1 and the work
that followed them. It remains a local preview: the strict quality gate and visual
browser acceptance are still outstanding, so the version number records delivered
scope, not certified quality. It also carries the pending notes that had accumulated
since 0.3.14-alpha.1. Every new drawing parameter is optional, so files written by
earlier versions open unchanged; files written here carry parameters that earlier
readers ignore, which loses editable line types, leaf mechanisms, page setup and
painting settings but not the visible geometry.

## Breaking changes

- Extended native-v2 paints and guide metadata require the updated reader. Migration: preserve original files and use this version for new saves; older readers may reject or discard these extensions.

## New features

- Work on several documents at once: New document and the tab strip plus button open a blank document in its own tab, and each tab keeps its content, undo history and selection. Tabs close one by one and show an unsaved-changes marker.
- Add File > Clear to empty the active document, undoable, and ask in an in-app dialog before clearing or closing unsaved work.
- Save projects with the .xds extension the documentation defines; files saved earlier as .ximply still open.
- Draw connected wall runs where each click continues from the previous end with exact shared joints, choose whether a wall is centred on the drawn line or has a face on it, and end the run with Escape.
- Give each door or window leaf its own mechanism, hinged, sliding, folding, pocket or fixed, choose how many leaves and the wall face they open towards, and add a passage without leaves.
- Add a straight stair flight with a configurable width, length, number of steps and walking direction.
- Set the line type of any stroke: solid, dashed, dotted, axis or a custom sequence of up to six dash and gap lengths.
- Add chain dimensions, which measure consecutive spans against one offset line, and radius and diameter dimensions with their standard prefixes, one arrow on the arc or two through the centre and an optional centre mark.
- Measure in metres, choose where the label sits along the dimension line, and unify the scale and label format of every dimension in the document with one switch.
- Combine walls with the boolean operations and keep them parametric: collinear runs merge, a crossing wall splits the one it crosses, intersecting keeps the crossing piece and excluding keeps every arm. Ordinary artwork still combines into one plain object.
- Set up the document from the transform tools: paper, screen and animation formats with output resolution and orientation, ruler units, margin guides with their centres, background colour, registration marks as a locked layer, and expanding or cropping the page.
- Resize the page on the canvas by dragging handles on its corners and edges, with the rulers following live, or crop it by dragging the area to keep while the rest is dimmed. Escape cancels and one undo step restores the page.
- Paint the page background like any other fill, with opacity, a colour picker and quick swatches for black, white, blueprint blue, chroma key green and no colour, which leaves the page transparent.
- Add a transform pivot that scaling, rotation and mirroring work about. It starts at the geometric centre of the selection and is dragged by its own mark while unlocked, travels with the objects when they move, returns to the centre on a double press, and snaps to the centre, to the selection box, to artwork vertices and dimensions and to the active rulers, guides and grid. Its own controls lock it, show it and switch its magnetism.
- Choose how the area selectors pick objects: every object the area touches, or only the ones it encloses.
- Add brush subtools for the round, flat, calligraphy, marker, airbrush and pencil tips, with a control bar for the brush and the eraser: pressure, opacity, cadence, diffusion, a speed variation slider that runs from thinner to thicker around the nominal size, a blend mode and tip angle where they apply, and a sample stroke that previews the result.
- Add a zoom area subtool: drag a rectangle and it fills the visible workspace on release; Ctrl with Space and a drag does the same with any tool active.
- Add an Appearance section to the settings with the theme and how transparency is displayed, and choose how many decimal places measurements are shown with.

## Improvements

- Apply drafting rules to linear dimensions: labels aligned with the line and never upside down, the line broken around the label when it fits, arrowheads moved outside and the label placed beyond the nearest end when the span is too small, a gap at the measured points, an overshoot past the extension lines and 3:1 arrowheads.
- Pre-mark the snap point of the dimension tools with a small blue square on vertices, intersections, edge midpoints and points on edges, and preview the actual dimension while choosing its side and offset.
- Snap new dimensions to the anchors and extension ends of existing ones and share their offset line when parallel, whenever dimension magnetism is on.
- Snap wall drawing to existing wall ends and axes before the grid, and lean it to the nearest 45 degree direction within six degrees, which keeps plans orthogonal; a wall joint still wins over the tendency.
- Draw door and window frames in the wall beside the clear opening, draw hinged leaves as panels with thickness towards the opening, and draw leaf travel as a broken projection line in the editor and in SVG exports.
- Give new walls and pillars a construction appearance and draw openings as outlines instead of using the current drawing colours.
- Name the pen tool Bézier, give its subtools and each brush tip an icon drawn in the same language as the control bar, and continue an existing unlocked open path when either of its ends is clicked, while a locked path still starts a new object.
- Name each typography measure in the text properties by an icon and a tooltip rather than a written label, with icon and control on one line.
- Lay out every panel header in the right column the same way, chevron and name together on the left and anything else pushed right, on a raised band closed off by a rule while the panel is open.
- Show the guidance of the blend panel as one tip at a time, marked by a bulb, and only where the panel is blocked; nothing is shown while a blend can simply be made or edited.
- Show an icon beside each boolean, align, transform, blend and grouping action, shorten the dimension and floor plan forms, group the opening leaves and the ruler tick switches under their own headings, and align each setting with its control.
- Use one scrollbar appearance across the shell, give the context bar and the document tab strip the height their content needs, move the workspace choice to the header beside the language and show only the fill in the appearance block while the brush is active.
- Open projects in the current tab when it is an untouched blank document, otherwise in a new tab, and remove the redundant quick Fill, Stroke and Width rows from the tool rail.

## Fixes

- Keep each fixed dimension point after a click: the canvas treated the pointer capture released after every click as a cancellation, so the third click never created the dimension.
- Draw walls as complete rectangles: composing their outlines dropped one corner, so a wall appeared as a triangle with its start edge collapsed.
- Open the document dimensions dialog from its toolbar button, which did nothing because the command was only registered for keyboard shortcuts.
- Open every dropdown on the theme colours: the property and header selects painted no background of their own, so under the dark theme the option list opened white with pale text.
- Let the pivot mark take its own press wherever it rests; it used to hand the press to the object under it, which made the pivot unreachable at its default place.
- Draw the two speed variation marks as round dots of a fixed size, centred with the slider; the larger one was stretched into an ellipse by the row.
- Accept stair parameters in the floor plan property panel, and replace the native browser confirmation used by New document.
- Generated documentation navigation is identical on Windows and POSIX hosts, with forward-slash links and case-sensitive document order.
- Load the full editor stylesheet directly in production so the Content Security Policy does not leave the interface unstyled. Rebuild the local containers to apply the correction.
- Use localhost:8090 by default for the local editor to avoid conflicts with port 8080. Existing installations should set XDS_PORT=8090 in .env.local and restart; credentials and saved projects are preserved.

## Security

- Validate dash sequences, leaf mechanisms, opening sides, wall alignment, stair parameters, page setup and background paints in the native parser and in the authenticated API before storage.
- Revalidate every restored local draft with the native document parser and bound local recovery to 12 tabs of 4 MB each.
