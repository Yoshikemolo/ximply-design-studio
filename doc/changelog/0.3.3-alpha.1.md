# 0.3.3-alpha.1 — Canvas cursor axes

## Breaking changes

None.

## New features

- Show horizontal and vertical guides across the canvas, intersecting at the pointer, with a crosshair cursor.
- Enable or disable cursor axes with a Settings toggle; the choice persists between sessions and is independent of the tool-icon setting.

## Improvements

- Keep guides aligned through canvas zoom and scrolling, clipped to the canvas, and hidden outside it or while editing text.

## Fixes

None.

## Security

None.

## Engineering

- Extend existing local input preferences with an optional boolean; existing settings default to enabled and native documents remain compatible.
