# 0.3.6-alpha.1 — Contextual object and Bezier menus

## Breaking changes

None.

## New features

- Right-click canvas objects, groups, guide lines or layer rows for grouped visibility, deletion and stacking actions. Move one step or to either end within the containing group; groups move as complete units.
- Right-click selected Bezier anchors or handles to convert corner/smooth nodes, collapse or expand either handle independently, or delete the vertex.
- Show current configured shortcuts when the contextual action matches a registered command; support keyboard navigation and outside dismissal.

## Improvements

- Preserve native context menus in text fields. Locked targets disable destructive actions; stale targets are rejected after document edits.
- Display explicit units beside additional dimensional properties. The canvas cursor remains hidden while its axis guides are visible, independently of the optional tool badge.

## Fixes

- Keep guide context menus accessible when guides are locked without permitting locked dragging.

## Security

None.

## Engineering

- Context targets capture document revision, exact layer/group scope and node indices. Actions are undoable and do not modify unrelated siblings.
