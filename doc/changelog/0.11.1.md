# 0.11.1 — Destructive actions in red and a tidier tool rail

A feedback patch on 0.11.0. It remains a local preview: the strict quality gate is paused
and outstanding.

## Breaking changes

None.

## New features

None.

## Improvements

- Every deleting action, in Edit > Delete, the Layers panel, the swatches, the context menu, the administration workspace, its bulk actions and the confirmation that asks before deleting, shows a trash icon and red text, so it reads as dangerous.
- The tool rail blocks keep an even spacing, the fill and stroke squares at the foot of the rail sit further apart, and the whole rail fits a full HD screen without scrolling.

## Fixes

- The tool rail no longer shows a horizontal scroll bar when its vertical scroll bar appears.
