# 0.3.1-alpha.1 — Preview identification and menu focus fix

A compatible feedback patch on the drawing preview branch.

## Breaking changes

None.

## New features

- Run the local launcher with info to identify the source version, branch and commit without starting Docker or reading credentials.

## Improvements

- Print the source version, branch and commit after successfully starting the local preview. About and the footer show the new preview version.

## Fixes

- Close main menus and tool flyouts when leaving the browser window; preserve expandable inspector panels and reset temporary input state.

## Security

None.

## Engineering

- Add regression checks for window-blur dismissal and checkout identification, including operation without Git.
- Preview publication does not certify the strict integration gate; existing quality and browser-acceptance limitations remain.
