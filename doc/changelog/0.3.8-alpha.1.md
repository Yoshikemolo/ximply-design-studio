# 0.3.8-alpha.1 — Settings category navigation

## Breaking changes

None.

## New features

- Navigate settings through a left-hand category menu and edit only the selected category in the right-hand panel.

## Improvements

- Preserve all existing settings and their values, with localized category navigation, keyboard access and responsive layout.
- Keep long forms separately scrollable and cancel unfinished shortcut recording when changing categories.

## Fixes

None.

## Security

None.

## Engineering

- Record the owner's settings layout requirement in repository instructions and UX guidance for future categories.
- Record undo-memory limits, clearing history, temporary directory and default work directory as future requirements, without exposing unimplemented controls.
