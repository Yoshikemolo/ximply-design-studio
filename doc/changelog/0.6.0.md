# 0.6.0 — Bezier drawing as Illustrator does it

This release follows chapter 3 of the Illustrator CS3 Help for drawing and editing
paths: the Pen with its cursor marks, modifiers and automatic add and delete; anchors and
segments chosen and shown the way Illustrator shows them; the Pencil, the Smooth tool and
a new vector Paintbrush with their fidelity and smoothness; and the Object Path commands.
It also gathers the corrections made since 0.5.0. It remains a local preview: the strict
quality gate and visual browser acceptance are still outstanding, so the version number
records delivered scope, not certified quality.

## Breaking changes

- A path may carry a brush painted along it, which the Paintbrush draws. Migration: a document holding a brushed path is refused by earlier versions of this editor and of the API; keep a copy of the original, or take the brush off the paths in the path panel before opening the document there.
- B selects the new vector Paintbrush instead of the raster brush, as it does in Illustrator. Migration: saved keyboard settings that still gave B to the raster brush as its old default hand it over automatically; to keep painting pixels with a key, assign one to the raster brush in Settings, Keyboard shortcuts.

## New features

- Draw with the Pen as in Illustrator: a click sets a corner and a drag a smooth anchor; Shift keeps a click on the angle increment; Space moves the anchor being placed; Alt during a drag splits the handles; a press on the first anchor closes the path and a drag there shapes the closing curve; a click on the last anchor takes its handle in and a drag pulls a new one; an endpoint of an open path continues it, the endpoint of another joins it, and Ctrl-click away from every object leaves the path open.
- Show beside the cursor what a path tool would do: a new path, a continuation, a close, an added or deleted anchor, a conversion, a join or a freehand stroke.
- Add and delete anchors with the Pen over a selected path, keeping the shape when an anchor goes; Shift, or a preference, keeps the Pen drawing. Alt turns the Pen into Convert Anchor, Add Anchor into Delete Anchor and back, the Scissors into Add Anchor and the Pencil into the Smooth tool.
- Convert anchors as Illustrator does: a drag from an anchor pulls out two handles that move together, a click takes them in, and a drag on a handle breaks it away.
- Choose segments with the Direct Selection tool and reshape a curve through the point grabbed, or move a straight segment whole; choose all the anchors of a filled path with a press inside it, and the anchors inside a marquee across objects, which then move together. Delete removes the chosen anchors and segments and leaves the rest as open paths.
- Select groups outward with the Group Selection tool, beside Direct Selection and under Alt from it.
- Fit the Pencil's strokes with Bezier curves by Fidelity and Smoothness, close them with Alt, extend or redraw a selected path started near, and join two selected paths with Ctrl.
- Smooth the stretch of a path the Smooth tool is dragged along, and erase with the Path Eraser only what it passes over, keeping the rest curved.
- Draw vector strokes with the Paintbrush, on B: a fitted path carrying a calligraphic brush of its own diameter, roundness and angle, painted the same on the canvas, in SVG and in PDF, which the path panel applies, changes and takes off.
- Set the options of the Pencil, the Paintbrush, the Smooth tool and the Eraser by double-clicking the tool, with Illustrator's ranges and defaults, kept between sessions.
- Join paths with Ctrl+J, asking for a corner or a smooth point when the ends meet, and Average anchors along either axis or both with Ctrl+Alt+J.
- Simplify paths with a preview, curve precision, angle threshold, straight lines and the original shown behind, counting the anchors before and after.
- Convert chosen anchors to corners or smooth points, remove them, and cut the path at them from the path panel; select stray points.
- Stretch a path with the Reshape tool, beside Scale, from the focal points it is pressed on.
- Erase vector artwork with a nib of its own shape, sized with [ and ], across every object when nothing is selected, on a straight line with Shift, or over a whole marquee drawn with Alt.
- Turn a text into one shape per letter, each with the holes of that letter inside it, the letters of a word grouped together, the words grouped into the text and the whole thing kept inside the group the text belonged to. A selection of several texts outlines every one of them.
- Import encapsulated PostScript drawings, the EPS files Illustrator and CorelDRAW export: their paths, colours and stroke widths arrive as editable layers, read with the names of the language and the aliases each program defines for them, and whatever falls outside that vocabulary is reported.

## Improvements

- Show chosen anchors solid and the others hollow, handles only where Illustrator shows them, and the anchor under the pointer ringed, with anchor size, handle style, handles for several anchors and the highlight set in a Selection and anchor display category of Settings.
- Carry a licence: the Ximply Design Studio Limited Use Licence, which lets anyone read the software and run it to evaluate it, to study it or for their own internal use, and keeps distribution, modification and commercial use for the author, who may grant them in writing.
- Show the editor at work in the readme, above the address of the published preview, https://xds.ximplicity.es, and clone the default branch instead of a branch that was retired.
- Publish the editor on the owner's preview address with `scripts/deploy-production.ps1`, which builds the checkout, uploads it under the commit it was built from, moves the link the web server reads and reloads it only after the configuration is accepted, keeping the earlier releases so a return to one of them is a single command.
- Name the import command Import, not Import image: it reads drawings as well as pictures.
- Show or hide the column of tools from View, Layout, like the other blocks of the workspace. The canvas takes the width the column leaves, and the choice is remembered.
- Build the spatial preview by group, one plane per group, and offer a parallax view whose camera faces the planes and follows the pointer.
- Show the same credits in the footer as the other product of the company: the copyright with the company and the author, the version that opens the about screen, and the links to LinkedIn, to Ximplicity and to the repository, each in its own tab.
- Give the text tool a list of its own, so Create outlines sits beside the tool that writes the text; every tool family with a command of its own shows the arrow that opens its list.
- Name what an outline of the stroke left alone in a selection of several objects, instead of doing nothing visible.

## Fixes

- Run the keyboard commands of the editor while a text is being written or a field has the keyboard, committing what is written first, as Illustrator does; a field keeps the keys that write in it.
- Create outlines and outline stroke did nothing from the Object menu, the list of the text tool or the context menu; every surface now reads one table of commands.
- Keep the keyboard settings saved when a new command appears, instead of replacing every customised shortcut with the defaults.
- Show and hide the Pivot and Selection blocks of the workspace from the Layout menu, whose entries did nothing.
- Create outlines produced one shape for a whole text, in the colour of a new path, with open letter contours; each letter is now its own closed shape in the paint the text carried.
- Keep the appearance popovers of the fill and the stroke on the screen.
- Continuing a path from its endpoint no longer adds a second anchor on top of it.

## Security

None.

## Engineering

- Share one least-squares fitter among the Pencil, the Smooth tool and the Paintbrush, and keep path editing, erasing and joining in the domain package, where they are tested against geometric oracles rather than against their own output.
- Record the brush carried by a path as a proposed decision, ADR-0032, awaiting owner review, since it extends the native format.
