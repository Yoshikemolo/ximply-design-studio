# 0.3.12-alpha.1 — Area selection tools

## Breaking changes

None.

## New features

- Add rectangular, circular and freehand lasso subtools to Selection, with localized icons/tooltips and live area previews.
- Reuse the last area-selection mode when dragging empty canvas with the normal Selection tool; persist the last mode locally.
- Hold Shift during area selection to toggle reached objects against the starting selection, adding unselected objects and removing selected ones.

## Improvements

- Preserve ordinary object movement and transforms, respect groups and locked/hidden layers, and exclude editing guides.
- Cancel area selection with Escape or pointer cancellation without changing artwork or document undo history.

## Fixes

None.

## Security

None.

## Engineering

- Use bounded geometric area intersection and document-coordinate previews without changing native documents or API contracts.
