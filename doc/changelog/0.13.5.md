# 0.13.5 — A pool of models for the agent tools

A feedback patch on 0.13.4. It remains a local preview: the strict quality gate is paused and
outstanding.

## Breaking changes

None.

## New features

None.

## Improvements

- Bitmap and vector requests each have a pool of models, newest first. When the project of the token cannot use a model, the next one is tried until one answers, and the one that worked is tried first next time. The model settings accept a comma-separated list to choose the pool.
- Test connection names the model of each pool the project will use, or the pool it can use none of.

## Fixes

- A vector request no longer fails when the project of the token cannot use the first text model but can use another.

## Security

- Only a refusal to use a model moves to the next one; a missing credit, a rate limit or any other refusal stops at once, so that no credit is spent on requests bound to fail.

## Engineering

- SC-0154 records the model pool oracle.
