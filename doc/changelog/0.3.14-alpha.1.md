# 0.3.14-alpha.1 — Parametric floor-plan tools

## Breaking changes

- New native-v2 procedural parameters and wall-host references require compatible readers. Migration: preserve original files and use this version or newer for new saves; SVG/PNG retain visible geometry but not editable parameters or host relationships.

## New features

- Add procedural wall, door, window and pillar tools with editable parameters and generated vector geometry.
- Configure door/window leaf widths and supported swing or sliding representations; choose rectangular or circular pillars.
- Host openings on walls so their cutouts and placement follow the host.

## Improvements

- Join compatible crossing walls and shared end faces while preserving source objects, group membership and ordinary artwork stack boundaries.
- Close shared wall corners with miter joins, retaining flat free endpoints and bounded bevel fallbacks at acute angles.
- Recompute supported procedural contours from native parameters for Canvas rendering and SVG export; cut openings only from their host and retain physical wall thickness under shear.

## Fixes

- Reject procedural elements and dimensions in native blend definitions before derived blend geometry can overwrite them.

## Security

None.

## Engineering

- Use a bounded local registry of trusted geometry functions; native files store declarative parameters, never executable code.
- Validate parameter shapes and host references in both the application and API.
- Keep this preview scoped to two-dimensional vector plans, without BIM, structural validation, building-code certification or external CAD-format fidelity.
