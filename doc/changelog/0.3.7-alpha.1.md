# 0.3.7-alpha.1 — Typography and localized action icons

## Breaking changes

- Optional native-v2 typography and text-layout metadata may be rejected by older readers. Migration: preserve original documents and use the updated application for new saves; legacy text without metadata retains its rendering behavior.

## New features

- Select font family, weight and style; configure leading, letter, word and paragraph spacing, horizontal and vertical scale, baseline offset, alignment and decoration.
- Text property toggles control wrapping, automatic English/Spanish hyphenation, content sizing, horizontal or vertical automatic sizing and shrink-to-fit within a fixed frame.
- Text layout uses shared canvas/SVG glyph positions and browser font measurements. Automatic frame changes and multi-object property updates are undoable.
- Add a persistent global guide-lock button immediately before Guides, reusing the layer padlock icons. Existing guides cannot be dragged while locked; rulers still create new guides.

## Improvements

- Replace compact action labels with icons and localized tooltips while preserving form labels, accessible names and menu shortcuts.
- Display text dimensions and spacing in configured units while retaining canonical pixel values.

## Fixes

- Preserve fixed text frame dimensions during text editing; automatic sizing is explicit.

## Security

None.

## Engineering

- Add strict matching frontend/API text metadata validation and bounded layout calculations.
- Pin the hyphen dependency to 1.14.1 for automatic English/Spanish hyphenation; retain its distributed license notice.
- Fonts depend on system availability. Inline editing uses a native textarea: its caret and selection may differ from composed artwork for justification, automatic hyphenation or scaling. This release does not implement per-character styles, linked frames, text on paths or complete OpenType controls.
