# 0.13.6 — Model progress and long requests

A feedback patch on 0.13.5. It remains a local preview: the strict quality gate is paused and
outstanding.

## Breaking changes

None.

## New features

None.

## Improvements

- While a request runs, the panel says which model it is trying, "Trying the best model to do this", and when the project cannot use one, which it left and which it tries next; it counts the seconds and, after the result, says which model made it.

## Fixes

- A vector drawing that takes the model more than a minute no longer ends in a 504: the answer streams its progress with a heartbeat every 15 seconds, and the local proxy passes each line on at once and waits up to 300 seconds. On 2026-09-24 a drawing by the text model took about two minutes and was lost to the one-minute limit of a proxy that had not reloaded its settings.

## Security

None.

## Engineering

- SC-0154 records the progress oracle. A running live proxy needs a restart, or `nginx -s reload`, to take the new settings.
