# 0.12.0 — AI Tools panel

The AI Tools tab gets its panel. It needs advanced mode: a local Keycloak, a licence with
the AI Tools permission and the user's own OpenAI API token in Settings > External tokens.
The online preview has no Keycloak and stays in demo mode, where the tab explains what is
missing. It remains a local preview: the strict quality gate is paused and outstanding.

Limits: this checkpoint was not verified against the live provider, which needs the owner's
token; the Settings > AI Tools category, the conversation and the proposal flow are not
implemented; and an empty document cannot be the context, since the image endpoint needs a
picture to edit.

## Breaking changes

None.

## New features

- The AI Tools panel: the selection or the whole document as the context; quick actions to change the style, reinterpret in a style, rescale, improve quality, remove watermarks, clean the background, remove an object and convert to paths and groups; a prompt; and a creativity slider from Precise to Creative.
- Saved prompts: save the prompt, action and creativity under a title, mark favourites and load from a list that includes seven defaults. The prompts are kept per user by the API.
- Generate stays at the bottom of the column, with a moving bar and the phase while the context is sent and the model answers, and Cancel while it runs. The panel lists what was sent: the prompt, the selected objects as data, the selection as PNG, the whole document as PNG and the modifiers. Ctrl+Enter in the prompt generates.
- The result is inserted as a new object above the selection and outside its groups: a picture fitted into the selection or the page, or editable paths and groups for Convert to paths and groups. One undo removes it. Repeat sends the last request again for another result.

## Security

- The API validates every request before calling the provider, uses the token of the user who asked, keeps at most four requests running, and audits the action, scope, sizes and outcome without the prompt or pixels.
- Drawings the model returns are screened for scripts, event handlers and javascript links before the editor imports them.

## Engineering

- New API routes `/api/ai/generate` and `/api/me/prompts`, with a provider port and an OpenAI adapter; the image and text models can be set with `XDS_OPENAI_IMAGE_MODEL` and `XDS_OPENAI_TEXT_MODEL`.
- The local nginx allows the model four minutes and 60 MB requests on `/api/ai/`.
- Recorded SC-0150 to SC-0154 and the owner decision to insert results directly, which defers the proposal flow of SC-0120.
