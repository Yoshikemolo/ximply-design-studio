# SEC-0001 — Identity and project isolation

Status: Proposed
Owner: Jorge Rodriguez

## Constraint
Validate bearer JWT and current project membership on every resource use; derive actor on server.

## Verification oracle
A valid user from project B receives no project A metadata or bytes.

## Enforcement
Server-side checks and adversarial integration tests; client visibility is UX only.

## Evidence
Planned. No implemented security control is claimed by this document.
