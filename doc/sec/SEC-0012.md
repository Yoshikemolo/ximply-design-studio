# SEC-0012 — External model data egress and output authority

Status: Proposed
Owner: Yoshikemolo

## Constraint

- Nothing leaves for an external provider unless AI Tools are enabled and the designer
  sends a request; the request carries exactly the attachments the composer showed.
- Each user's provider token lives only in the API service, encrypted at rest and tied to
  the verified subject. It never reaches the browser, logs, audit records, documents,
  exports or repositories, and one user's token is never used for another user. Settings
  shows only a masked form, the prefix and the last four characters (owner decision of
  2026-09-24).
- Model output is untrusted data. It is validated against a closed operation catalogue,
  the permitted scope and document limits by the API service before it is shown, and it
  is applied only by the designer's action through ordinary editor commands.
- Content in documents, prompts or model output cannot grant permissions or widen the
  scope (SEC-0004).
- Logs and audit records hold metadata and digests only, never prompt text or pixels
  (SEC-0010).

## Verification oracle

SC-0119, SC-0121 and SC-0122: payload equality at the adapter boundary, refused
out-of-scope and injected operations, and absence of the key and content in every
output channel.

## Enforcement

Server-side validation in the API service and adversarial integration tests. The
panel's controls are user experience only and are not the enforcement point.

## Evidence

Partly implemented in 0.12.0 (SC-0154): the request is validated in the API before any
provider call, the user's token is used only for that user's request, the audit record holds
the action, scope, sizes and outcome without the prompt or pixels, and SVG answers are
screened for scripts, event handlers and javascript links before the editor imports them.
Model pictures are inserted as new objects the user can undo; nothing is changed in place.
The operation catalogue and scope checks of the proposal flow are not implemented. Human
security review is outstanding.
