# SEC-0010 — Confidential telemetry and cache

Status: Proposed
Owner: Jorge Rodriguez

## Constraint
Redact tokens/pixels/prompts; authorize cache and linked asset access, enforce retention policy.

## Verification oracle
Log captures contain no secret and revoked links cannot renew cached asset access.

## Enforcement
Server-side checks and adversarial integration tests; client visibility is UX only.

## Evidence
Planned. No implemented security control is claimed by this document.

Preview note (0.4.0): open documents are kept as unencrypted local drafts
in the browser origin only, bounded to 12 tabs and 4 MB each, and are revalidated by
the native parser on restore (PLAN-0006-0001). This is not a server-side control.
