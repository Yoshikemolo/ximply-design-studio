# SEC-0003 — Plugin least privilege

Status: Proposed
Owner: Jorge Rodriguez

## Constraint
Broker sandboxed plugin access with scoped capabilities and quotas; deny ambient network and tokens.

## Verification oracle
Plugin cannot call a denied tool by bypassing UI or forging manifest grants.

## Enforcement
Server-side checks and adversarial integration tests; client visibility is UX only.

## Evidence
Planned. No implemented security control is claimed by this document.
